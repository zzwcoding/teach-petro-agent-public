① 模型清单（主用 + 备用）
主用：Petro-72B 使用中
内网部署，走 OpenAI 兼容接口——所有业务代码只认「主用模型」这个名字，不直接连模型。
备用：DeepSeek 备用
主用故障时自动顶上，用户无感知；主用冷却期满自动切回。
模型清单与主备切换
模型清单（model_list）＋主备切换（fallbacks 主→备）＝网关配置契约的两件，见下方预填配置逐字段对应（m2 卡 · F2）。
② 切换与重试参数（可改，保存为演示）
连续失败几次判为故障
故障后冷却多少秒不用主用
失败自动重试几次
单次调用最多等多久（秒）
已保存（演示）——真实实现是写回网关配置文件并热加载。
重试 / 冷却 / 超时字段名
allowed_fails＋cooldown_time（故障冷却）、num_retries（重试，只算网关层）、request_timeout（超时）——字段名见下方预填配置（m2 卡）；界面模型软件自身的重试已关掉为 0，防止「网关重试一遍、软件再重试一遍」越试越多（W-F2-4）。
③ 配置文件预填（与模块卡契约逐字段一致）
下面这份就是本页表单对应的真实配置文件内容（演示预填）；改表单＝改这份文件的对应字段。
# 文件：app/gateway/config.yaml（演示预填；字段＝m2 卡配置契约，一条不多不少）
model_list:                          # 模型清单：主用 + 备用
  - model_name: petro-llm            #   主用别名「petro-llm」＝Petro-72B（业务代码只认别名）
    litellm_params:
      model: openai/petro-72b          #   Petro-72B 主模型，OpenAI 兼容接口（换模型只改这一处）
      api_base: ${PETRO72B_BASE_URL}  #   内网地址外置，不写死在代码里
  - model_name: deepseek-backup      #   备用：DeepSeek
    litellm_params:
      model: openai/deepseek         #   同为 OpenAI 兼容形状
      api_base: ${DEEPSEEK_BASE_URL}
fallbacks:                           # 主用故障 → 自动切备用（点「故障演练」验的就是这行）
  - petro-llm: [deepseek-backup]
num_retries: 3                       # 重试只走网关层；软件侧 max_retries=0 防重试套娃
allowed_fails: 2                     # 连续失败满 2 次 → 判定故障
cooldown_time: 60                    # 故障冷却 60 秒，期内不再选主用
request_timeout: 30                  # 单次调用超时（秒）
配置契约五件
配置契约五件＝model_list（Petro-72B 主＋DeepSeek 备）/ fallbacks / num_retries / allowed_fails＋cooldown_time / request_timeout（m2 卡 config.yaml 契约 · F2）；白名单式登记，不在契约里的字段这里不编。
