这是什么（首次访问先读）
展开完整说明

一句话：这是 Petro-Agent 油田智能平台的客户端原型——界面按真实系统的产品外观绘制、内置演示数据可点击交互，不连真实系统；每个界面底部都有一条"契约溯源"，说明它来自后台哪条真实契约。

· 产品级外观：左侧导航 + 顶栏 + 真实控件，可对照讲解给客户听；界面里的灰色小字注解是给工程师看的实现说明，可折叠、可跳过。
· 假数据可点：按钮、开关、进度条、思考过程都能点，页面里跑的是内置假数据，不碰任何真系统。
· 每页有后台契约：界面不是拍脑袋画的，页底溯源条写明出处。
· 本页是平台总览：22 个页面都能从下方站点地图或左侧导航到达。
三句话用法
① 说人话——界面上的标题、按钮、提示都用油田工作者的日常话，不用懂技术。
② 看灰字——界面里的灰色小字是给工程师看的注解（后台怎么实现），不认识可以直接跳过。
③ 底部溯源条——每页最底下有一条"契约溯源"（F 号 · 模块卡 · 走查断言），说明这个界面对应后台哪条功能契约。

A 区 · 工作台
角色：老王 / 小李 / 主任		 问一问（智能对话） 全体业务用户的默认首页：打字或语音提问，看得见平台的思考过程，答案带出处，还能说"做成 PPT / 配张图 / 出段语音"。
井档案页（井 360°） 老王 / 小李：搜一口井一页看全——档案、近 30 天产量、措施记录、检修台账；页内直接追问，系统自动带上本井背景。
变更审批台 阿强 / Owner：看 AI 的变更建议卡（改动 / 理由 / 影响测算 / 副作用），高风险变更必须人点批准；批准只写变更记录，生产原表不动。
B 区 · 报告库
角色：小李 / 质量管理员		 报告库 小李：上传报告，看"解析 → 切段 → 建索引"走到哪一步；按库配四个索引开关和切段方式。
答案出处（原文定位） 小李：核对 AI 答案——看"命中句"和它带出的完整段落，每段带报告名 + 井号 + 章节的来源标签。
常见问答库 小李维护、全体受益：常问的一问一答直接入库，命中秒回；相似问法合并；"不该答的问题"登记在案。
报告百科（Wiki） 小李：200 页英文完井报告自动变成一页中文百科（摘要 / 关键参数 / 表格）；词条自动变链接，改错一键回滚。
关系图谱 小李：看从报告里抽出来的关系网（井—位于→区块、注水—受效→油井）；问关系走图谱，不翻全文。
C 区 · 指标与术语
角色：Owner / 阿强		 指标与业务术语库 阿强维护、全体查阅：四本账——业务术语 / 指标口径 / 对象与关系 / 分析剧本；每条带负责人、状态、来源、版本，可导出给别的系统。
修改审批台（提案池） Owner / 治理领导组：AI 的修改建议统一进池子（考核没通过 / 自动体检发现 / 用户反馈），过安检、负责人批准才生效，可回滚。
发布前安检（五级检查） 阿强：任何口径、术语修改发布前过五道检查——格式、引用、查询安全、负责人、成绩不降级；拦在哪道、为什么，看得见。
指标口径详情 Owner 维护、老王查阅：每个指标一页——定义 / 公式 / 单位 / 粒度 / 负责人 / 版本；一词两译会让提问的人选口径，不选按默认出数并标注。
D 区 · 设置中心
角色：阿强（界面统称"设置"）		 模型与线路设置 阿强：配主用 / 备用大模型，主模型坏了自动切备用；一键"故障演练"看切换日志；每次调用记账（用了哪个模型、多少量、多快、花多少钱）。
搜索与回答设置 阿强：平台找资料的顺序（先精确后模糊、逐级升级）、每路取多少条、怎么排序、引用长什么样、搜不到时怎么说。
安全与权限设置 阿强：查询安检（只放行查看语句、按人过滤数据行）、内容可信度分级、角色权限矩阵（看不到就是没权限，不是被拒）、敏感字段加密。
系统运行状态 阿强：开发库 / 生产库切换、缓存与对象存储连接状态、部署信息（国产化环境、加密算法用在哪）。
运行追踪与花费 阿强：一次提问的完整链路时间线——哪步慢、各步花费；预算超了自动切便宜模型，阈值可设。
数据接入与加工 阿强：数据源原样入库（任何数可追溯到原始文件某一行）；三种清洗路径；表映射成业务对象；三层加工出汇总大表。
E 区 · 考核与质量
角色：小李(质检) / 阿强		 答题考核（评估集） 小李出题考平台：标准问法 + 人工算好的标准答案，一键跑批看三大评分（忠实度 / 相关度 / 出处准度）；答错的登记成改进项。
数据质量台 小李：20 条质检规则配置与启停、发起质检任务出合规报告；问题单从分发一路流转到关闭；数据新鲜度水位。
知识体检 阿强组织 / 小李参与：给井、区块、指标做四维体检——资料全不全、逻辑顺不顺、数据覆盖够不够、关系健全不健全；附补全建议。
F 区 · 对外接口
角色：阿强		 对外接口（给外部 AI 用） 阿强：外部 AI 三种用法——直接调工具 / 参数不够时反问 / 长任务给任务号；内外同一套权限；大结果给"取货凭证"不给正文。
