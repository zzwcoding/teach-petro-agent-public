对外接口F 区 · 对外接口 · 阿强 · 把平台开放给别家的智能助手用

🔍 搜井号 / 报告 / 指标… 当前角色：阿强（本区默认） 演示环境

平台的用户不再只有人——上级单位、合作方的智能助手也能用它查数、查口径。这一页管三件事：对方怎么调（三种用法）、大结果怎么给（取货凭证不塞正文）、权限怎么不松（内外同一套安检）。

① 外部智能助手的三种用法
对方助手调「按井查产量」： 
请求：{ 工具："按井查产量", 参数：{ 井号："N-02", 月份："2026-08" } }
返回：{ 产油量：1,4xx 吨，口径：产量完成率口径 v3，出处：汇总层日报表 · 质检通过 }
对外工具清单说明
按井查产量按井 / 区块 / 月查产油产液（审定口径）
查指标口径问"递减率怎么算的"——返回定义、公式、负责人、版本
查井档案井的基本档案、状态、隶属区块
对外清单＝内部工具注册表按可见性过滤的结果：内部能用什么，外部就见什么，一件不多、一件不少——和内部用户同权同闸（W-F28-1）。
MCP tool 调用
黑话注：技术叫法 MCP tool 调用。
对方问得含糊，平台反问，不瞎猜： 
对方：查一下上个月的产量
平台：缺一个必要参数——你要哪个区块？（渤南 / 渤中 / 渤西）
对方：渤中
平台：好，渤中 2026 年 8 月产油 x,xxx 吨（口径版本 v3 · 出处见附）
缺参数就走"反问"，不做默认猜数——复用平台对内部用户同款的澄清问答（W-F28-2）。
MCP elicitation 映射
黑话注：技术叫法 MCP elicitation 映射到既有澄清闸语义（m7 卡）。
长任务不让人干等，受理即回一个任务号： 
对方：把渤南区块月度产量做成汇报材料
平台：已受理，任务号 task-7c2d。完成后可凭号取结果（也可订阅完成通知）。
（稍后）对方：task-7c2d 好了吗？
平台：好了 → 取货凭证见下（大结果不给正文，凭凭证自取）。
与内部"做汇报"走同一条异步任务链：受理即回＋任务号＋完成可查（W-F28-3）。
MCP tasks 映射
黑话注：技术叫法 MCP tasks 映射到内部队列 / worker（m4/m15 卡）。
② 大结果给"取货凭证"，不给正文（不撑爆对方）
对方要"全部在产井一整年的日产量明细"——几万行数据如果原样塞进对话，对方根本装不下。平台的做法：大结果落成生成文件，只发一张取货凭证＝几行预览＋一条下载直链，内容由对方凭凭证自取。

大结果句柄（artifact）
黑话注：大结果落生成文件（artifact 句柄），出门只带前几行预览＋预签名下载直链——"1–2 MB 不进上下文"（W-F28-4 · F27 沙箱大结果句柄）。样本行取自设定书 §A.2。
③ 行业化复用：这套东西搬去别的油田，什么能带走？
层是什么换一家油田能带走多少
领域对象层井 / 区块 / 指标 / 受效关系这些对象与口径的定义方式复用 90% 以上
映射层客户源系统的表怎么对到对象——逐张表的对应规则库复用 70% 以上——护城河所在
客户定制层各家的特殊报表与个性化流程逐客重做
核心论断："护城河不是对象清单，而是源系统→对象的对应规则库"；落地要配前置部署工程师（懂业务的人判断"200 列宽表拆成哪几个对象"），是行内陪跑不是替代决策的架构师（F54 · W-F54-1）。
④ 内外同一套权限——外部 AI 不能绕安检
外部智能助手走的门，和内部用户是同一扇：查询安全检查一道不少——只放行查看类语句、只认白名单里的表、按对方身份过滤数据行、强制限量。外部 AI 不能绕安检、不能多看一行。
"改定义"是另一扇门：外部对口径/术语只能提修改建议＋人工审批，而那条通道根本碰不到数据；日常这扇门能读、能执行动作，但改不了任何定义。
例：上级单位的 AI 系统问"渤海油田本月递减率"——它读到的是审定口径的数，不是原始表。
同权同闸与双通道分离
黑话注：外部调用与内部主循环同权同闸；管理通道 / 消费通道双通道分离——管理通道只能提建议＋人工审批、不能写数据；消费通道能读能执行、不能改类型定义（W-F49-1 · W-F49-2）。
