# prototype/DESIGN.md —— Petro-Agent 前端客户端低保真设计说明（单一真源）

> 配套：`index.html` 总导航；`assets/wire.css` 灰盒样式；`assets/wire.js` 假数据交互库（tab 切换/开关反馈/逐步点亮/弹层，data 属性驱动，零依赖）。
> 实现阶段只读不改本文件；发现规划有洞 → 停下提出来讨论。改页面先改这里。

## §0 设计原则（设计走查标准）

1. **不是演示，但要像系统**：界面按**真实系统的产品级外观**绘制（左侧导航 + 顶栏 + 卡片 + 真实控件，样式统一走 `assets/shell.css`）——给客户讲解时照着屏幕讲，不像设计稿。同时保留两条工程诚实线：每页底部 `.trace` 契约溯源条；技术黑话只许藏在可折叠的"ⓘ 工程注记"里（`details.note`），界面正文一律人话（§5）。
2. **说人话（界面语言纪律）**：页面标题、按钮、标签一律用 §5 右列的用户语言；§5 左列黑话只许出现在 `.cap` 标注和 `.trace` 条里。判断标准：老王（懂业务不懂 SQL）看界面不卡壳。
3. **能配的都配**：后台一切外置配置都有界面，预填内容 = 模块卡/PRD 真实契约文本，不编造配置项。
4. **给用户用的都规划**：角色各有默认首页与 ≥3 个可操作界面；不可见界面标灰（F48："不是被拒答，而是世界里没有"）。
5. **假数据交互**：静态页面但基本交互必须可用——全部内嵌假数据驱动（`assets/wire.js` + 每页内联 mock），不许是死图。每页的最低交互清单见 §1 各页"交互"行。
6. **取材纪律**：示例数据只用 `docs/business-setting.md` 既有事实 + PRD/模块卡契约；禁止发明业务事实。

## §1 页面 → 模块 → 功能 → 配置（分级总表，22 页）

> 每页五行：**为谁**/**后台模块**（溯源用，不进界面标题）/**功能**（用户语言）/**配置项**（落 §3 登记表）/**假数据交互**（实现最低标准）。

### A 区 · 工作台（角色：老王/小李/主任）

**A1 问一问（智能对话）** `A1-chat.html`
- 为谁：全体业务用户（默认首页）
- 后台模块：m1 底座 / m13 运行时 / m15 问智 worker
- 功能：①三种问法 tab——问报告 / 问数据 / 做汇报；打字或语音提问。②问数据能看到平台的"思考过程"：听懂问题 → 查哪些表 → 写出查询 → 安全检查 → 执行 → 核对结果，错了自动改（最多 3 次，改不动就明说转人工）。③答案带出处，点出处跳原文片段。④说"做成 PPT/配张图/出段语音"：任务进度条 → 产物卡一键下载。⑤左侧历史会话；断网重连自动接着答。
- 配置项：无（本页不配置；行为受 D1/D2 设置影响，页内用 `.cap` 注明）
- 假数据交互：点示例问题"上个月产量最高的三口井"→ 右侧思考过程逐步点亮（data-runflow，含一次自动改错的反思回边）；三 tab 可切；点引用卡展开原文片段；点"做成 PPT"→ 进度条走 → 产物卡出现；一个"模拟断线"按钮 → 显示续答提示。

**A2 井档案页（井 360°）** `A2-well.html`
- 为谁：老王、小李
- 后台模块：m16 对象关系 / m1
- 功能：①搜井选井（如 N-02），一页看全：档案 / 近 30 天产量 / 措施记录 / 检修台账。②页内直接问——背景资料系统自动带上，不用重复说哪口井。③点关系链下钻：井 → 措施 → 设备 → 检修。
- 配置项：无
- 假数据交互：切换井 select → 四张卡换假数据；点"它最近怎么样"→ 出现回答卡（标注"本页背景已由系统注入"）；点关系链节点展开下一层。

**A3 变更审批台** `A3-action.html`
- 为谁：阿强 / Owner（高风险终审）
- 后台模块：m17 校验链 / m8 权限 / m3 持久化
- 功能：①看 AI 的变更建议卡（例：N-06 配注上调 10%）——改动内容 / 理由 / 影响测算 / 副作用，像一份合同。②批准或驳回（🔒 高风险必须人点）。③批准后只写变更记录，生产原表不动；④审计行：谁 / 何时 / 哪个 Agent 提的 / 改了什么。
- 配置项：无
- 假数据交互：点"批准"→ 建议卡状态变"已执行" + 审计表追加一行；点"驳回"→ 弹出理由输入框。

### B 区 · 报告库（角色：小李 / 质量管理员）

**B1 报告库** `B1-kb.html`
- 为谁：小李
- 后台模块：m5 存储 / m6 索引 / m14 双索引
- 功能：①上传报告（客户端直传存储，不绕平台——`.cap` 注预签名）。②每份报告的处理进度：解析 → 切段 → 向量化 → 建索引，走到哪步亮哪步。③四个索引开关：语义索引 / 关键词索引 / 百科页 / 关系图谱，按库配（例：制度文件库关图谱省抽取费）。④切段方式选择（智能切段 256–1024 字 / 固定大小 / 大小段配合）。⑤处理完自动产出全文档摘要和"这份报告可能被问的 10 个问题"。
- 配置项：四开关；切段方式；索引期加法（摘要/问题块）
- 假数据交互：点"上传"→ 进度管线跑一遍；四个开关 toggle 有态；切切段方式 → 示例片段对照切换。

**B2 答案出处（原文定位）** `B2-chunks.html`
- 为谁：小李（核查 AI 答案用）
- 后台模块：m6 检索 / m14
- 功能：①按报告 / 片段浏览原文。②看"命中句"和它回捞出来的"完整上下文段"——小段负责被找到，大段负责被读懂（铁律：大段永远不直接出现在搜索结果里）。③每段带来源标签：报告名 + 井号 + 章节路径。④图片说明 / 图片文字两类特殊片段（问"岩性柱状图说的是什么"靠它命中）。⑤看不懂的引用号直接删掉，不显示。
- 配置项：无
- 假数据交互：点命中句 → 完整上下文段展开；切报告 → 片段列表换数据。

**B3 常见问答库** `B3-faq.html`
- 为谁：小李维护；全体受益（秒回）
- 后台模块：m6 FAQ
- 功能：①常问的一问一答直接入库，不再走报告检索，秒回（例：主任常问的"月度完成率口径"）。②相似问法合并。③登记"不该答的问题"（负例，不参与回答）。④与考核题集分账：考核用题集 = 评估资产，本库 = 服务资产，可互转不混用。
- 配置项：FAQ 条目；负例；扩检轮数
- 假数据交互："新增问答"表单提交 → 列表追加；点"合并相似问"→ 两条并一条。

**B4 报告百科（Wiki）** `B4-wiki.html`
- 为谁：小李
- 后台模块：m6 wiki 管线
- 功能：①200 页英文完井报告 → 一页中文结构化百科页（摘要 / 关键参数 / 井号链接 / 表格）。②词条自动变链接（如"渤中28-1"点一下跳井卡）。③每个库一个首页目录。④改错一键回滚，历史版本可看差异。
- 配置项：百科开关
- 假数据交互：点词条链接 → 跳到对应卡；版本列表点某版 → 展开差异对比；"回滚"按钮 → 当前版标记恢复。

**B5 关系图谱** `B5-graph.html`
- 为谁：小李
- 后台模块：m6 图谱 / m16 类型对号
- 功能：①看从报告里抽出来的关系网：井—位于→区块、注水—受效→油井。②问"哪些井受过 N-06 注水影响"走关系网回答，不靠翻全文。③配置抽哪些实体类型（默认 11 类）/哪些关系/多拿不准宁可不抽（防胡编）。④注记：图谱入库前过闸，对不上的关系不立边。
- 配置项：抽取设置（实体清单/关系标签/示例）
- 假数据交互：点节点 → 高亮相邻关系；实体类型开关 → 图例增删；三形态说明 tab。

**C4 指标口径详情** `C4-metrics.html`

### D 区 · 设置中心（角色：阿强；用户语言统称"设置"）

**D1 模型与线路设置** `D1-gateway.html`
- 后台模块：m2 网关
- 功能：①配主用/备用大模型（Petro-72B 主 + DeepSeek 备），主模型故障自动切备用。②重试次数 / 故障冷却 / 超时参数。③一键"故障演练"：关停主模型，看自动切换日志。④每次调用记账：用了哪个模型 / 多少 token / 多快 / 花多少钱。
- 配置项：模型清单 / 切换规则 / 重试 / 冷却 / 超时
- 假数据交互：点"故障演练"→ 日志表追加 fallback 行；参数编辑框可输入（假保存提示）。

**D2 搜索与回答设置** `D2-retrieval.html`
- 后台模块：m21 检索协议 / m6
- 功能：①检索顺序设置：先精确匹配（@指标/@井号）→ 再确定性查表 → 再语义+关键词两路搜索 → 逐级升级、可早停。②每路取多少条 / 两路结果怎么合并。③精排三选一：模型精排（快）/ 大模型逐个打分（准但贵）/ 复合分+多样性（防结果全是同一段）。④引用格式二选一：人读友好 [报告名 p.页码] / 防伪造编号 cN。⑤搜不到时的兜底话术设置。
- 配置项：瀑布参数 / 条数 / 精排档 / 引用格式 / 兜底
- 假数据交互：三档精排切换 → 各自说明和适用场景显示。

**D3 安全与权限设置** `D3-security.html`
- 后台模块：m17 校验链 / m19 注入防御 / m8 权限 / m11 国密
- 功能：①查询安全：只放行查看语句 / 可用表白名单 / 强制限量 / 按人过滤数据行。②内容可信度四级标注（系统>开发者>用户>数据），外发工具白名单。③角色 × 功能权限矩阵（五层：背景注入/自主查询/专业计算/写操作/治理约束）；实习生示例行——看不到就是没权限，不是被拒。④敏感字段加密清单（如手机号 SM4）/ 操作日志摘要留痕。
- 配置项：查询安检规则 / 行列权限 / 信任标 / 权限矩阵 / 加密字段
- 假数据交互：点矩阵某角色行 → 展开五层勾选明细；开关 toggle。

**D4 系统运行状态** `D4-system.html`
- 后台模块：m3 持久化 / m4 缓存 / m5 存储
- 功能：①开发库/生产库切换（PostgreSQL ↔ 金仓），连接串外置。②缓存 / 对象存储连接状态卡。③部署信息：Docker / 麒麟 OS / 离线交付；国密算法用在哪。
- 配置项：数据库连接 / 方言
- 假数据交互：切换数据库下拉 → 连接状态与方言差异提示变化。

**D5 运行追踪与花费** `D5-observe.html`
- 后台模块：m12 可观测
- 功能：①一次提问的完整链路时间线：哪步慢 / 各步 token 花费（给阿强排障）。②平台追踪字段 ↔ 行业标准（OTel）对照表——不丢不造。③预算熔断：超预算自动切便宜模型，阈值可设。
- 配置项：熔断阈值 / 追踪映射开关 / Langfuse 挂接
- 假数据交互：点某次运行 → 展开链路树；改阈值 → 提示生效。

**D6 数据接入与加工** `D6-pipeline.html`
- 后台模块：m20 转换分层
- 功能：①数据源原样入库（任何数字可追溯到原始文件某一行）。②三种清洗路径：规整表格自动识别 / 嵌套数据炸开 / 扫描件 OCR+人工复核。③表 → 业务对象映射配置（表→对象类型 / 行→对象 / 列→属性 / 外键→关系）。④三层加工视图：原始 → 清洗 → 汇总；汇总层星型模型（统计粒度=井×日，维度=井/日期，事实=产油/产液/压力）。
- 配置项：映射配置 / 分层加工
- 假数据交互：点表名 → 映射详情展开；层间切换 → 各层表清单变化。

### E 区 · 考核与质量（角色：小李(质检) / 阿强）

**E1 答题考核（评估集）** `E1-eval.html`
- 后台模块：m18 评估
- 功能：①建考核题集：标准问法 + 人工算好的标准答案（AI 只帮忙扩写问法，不造答案）。②一键跑批，看三大评分：忠实度 / 相关度 / 出处准度 + 按查询结果集比对（不认 SQL 文本一样）。③答错的登记成改进项，进 C2 提案池。
- 配置项：考核对 / 判分器 / 红队用例
- 假数据交互：点"跑批"→ 三指标分数填充、失败行标红。

**E2 数据质量台** `E2-quality.html`
- 后台模块：m20 质量

- 配置项：规则 / 质检任务
- 假数据交互：问题单"流转"按钮 → 卡片移到下一列；规则开关 toggle。

**E3 知识体检** `E3-checkup.html`
- 后台模块：m16 / m18
- 功能：给业务对象体检四维打分：资料全不全 / 逻辑顺不顺 / 数据覆盖够不够 / 关系健全不健全；附补全建议（缺负责人/缺来源/孤儿关系）。
- 配置项：无
- 假数据交互：点对象（井/区块/指标）→ 四维分数条 + 建议列表切换。

交互与呈现规范：
1. 样式只走 `assets/shell.css`；每页 `<script src="assets/wire.js"></script>` 收尾；交互优先 data 属性（`data-tabs`/`data-toggle`/`data-runflow`+`data-step`），不够再内联 JS。
2. 假数据直接内嵌 HTML 或内联 JS 常量；**禁外部接口、禁 CDN、禁框架**。
3. 每页交互数量 ≥ §1 该页"假数据交互"行清单；`data-runflow` 用于 A1 思考过程、B1 处理管线、C3 安检等"逐步点亮"场景（纵向用 `.steps`、横向用 `.flow`）。
4. 黑话只进 `details.note`（"ⓘ 工程注记"折叠块）与 `.trace`；正文/标题/按钮零黑话（§5 对照表）。
5. 配置页表单预填真实契约文本，允许输入但"保存"只做假提示；状态流转用 `.tag` 徽标表达。
6. **翻新既有 wire 页面时的铁律：内容与交互一律保留，只换壳**——不得因换壳丢掉任何示例数据、出处、工程注记、`.trace` 溯源条和 JS 行为。

## §7 V2 增量（2026-09-24 拍板，ADR-0001）

**一句话**：V2 用 Vite + React + antd5 重做 22 页的 UI 实现层，信息架构（§1）与内容资产不变。

- 技术栈红线：React 18 + antd 5 + Vite；**禁第二套 UI 框架/组件库**。

### 铁律继承（V1 → V2 迁移对账，基线 commit 0dbf32b）

1. §1 逐页"功能/配置/交互"清单不变；正文文案、示例数据、出处标注、工程注记内容、页底 `.trace` 一条不丢。

3. 交互剧本与 V1 一致（点示例跑思考过程/断线/产物任务/审批流转/跑批……），React state 重写。

### V2 升级标准（"真系统感"细则，实现与走查用）

- 每个数据面组件补四态：加载中（骨架屏/Spin）· 空态 · 失败态 · 成功态——V1 只有成功态。

- 质量门：ux-ui-kit 的 `design-qa` 43 门 + 对比度 ≥4.5:1 机检报告纳入每页交付检查。

### 里程碑

- P0 技术验证：脚手架 + 共享件（侧栏/顶栏/溯源条/工程注记 Collapse）+ A1 重做 → 用户观感拍板。

### V2 补充原则（2026-09-24 用户拍板，优先级高于本节上文）

**P-1 产品纯净原则**：页面=可用产品，不是原型、不是讲解稿。
- 页面正文**零讲解类内容**：工程注记、实现说明、"演示"字样、内联讲解文全部退出页面。
- 页底 `.trace` 契约溯源条退出产品页面（溯源信息回 DESIGN.md §1/§4，本来就是这里的真源）；如某页确需标注数据来源（如"口径：设定书"这类**业务**注记），用产品本身该有的小字标注形态（如表格脚注），不用讲解口吻。

**P-2 导览弹窗承载讲解**：每个页面一个"**演示导览**"入口（顶栏问号按钮），点开是弹窗：本页的点击顺序、每步看什么、界面会发生什么变化。讲解力全部收进这个可显隐的弹窗，页面本身保持纯净。弹窗内容=该页规格的"导览步骤"节。
