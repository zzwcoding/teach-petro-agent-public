什么是分析剧本
分析剧本＝一类问题（如"为什么下滑"）的固定做法：平台按步骤走，不自由发挥（W-F19-3）。两个剧本都取自设定书 §7。
剧本 1《产量下滑归因》
听到哪类问题开工："为什么下滑"
  1. 拉完成率与构成（产油 / 开井数 / 时率）
  2. 分解：新井贡献 / 老井递减 / 措施增油 / 停产影响（用指标 3 / 8 / 10）
  3. 归因分支：地质——含水上升？工程——检泵停产？管理——配产调整？
  4. 下钻受效关系与检修台账
  5. 生成归因报告
参数没给够怎么办（缺参策略）
时间窗默认最近 30 天、范围默认全区块，并明确标注"默认"
哪步要人确认
机器建议占比与置信度高→少问人；低→必须人工确认档位（设定书 §7）
交付物合同（输出合同）
