## 对外调用面总纲（合同常量）

**外部智能助手的三种用法＝协议化暴露三映射，平台内各有对应的一套、不另起炉灶**（页面「调用方式」映射表原句——"直接调对工具注册表清单、反问对缺参澄清问答、任务号对异步任务队列"；`F1.jsx` WAYS 注"对外配置映射位，一表两用"）。三映射名与「平台内对应」值为**合同值不可改**：

| 三种用法（页签名） | MCP 形态映射 | 平台内对应（页面 WAYS.maps 照抄） | 本合同端点 | 契约来源 |
|---|---|---|---|---|
| 直接调工具 | Tools（tools/list / tools/call） | 内部工具注册表按可见性过滤后的清单 | 端点 2 / 3 | F28 · lesson 30 主干一（W-F28-1） |
| 参数不够时反问 | Elicitation | 平台既有缺参澄清问答 | 端点 3（elicitation_required 结尾）＋ 4 | F28 · lesson 30 主干二（W-F28-2） |
| 长任务给任务号 | Tasks（异步任务） | 异步任务队列：受理即回＋凭号取结果 | 端点 5 / 6 | F28 · lesson 30 主干三（W-F28-3） |

**调用鉴权链（每一笔外部调用的过闸顺序，合同值）**：

```
Authorization: Bearer pa-live-…（F61 凭证明文，服务端比对指纹）
→ ① 身份解析（m1 verify_token 同闸：Key→服务账号＋档位；agent-card authentication："外部 Agent 默认只读档；行权限随档注入"）
→ ② scoped 默认拒绝（F48 五层裁剪：本次调用所需能力未在 Key.scopes 声明 → 403，拒绝帧与内部权限拒同形）
→ ③ 可见性过滤复核（调用目标必须在外部放行清单内——清单外直调 403，lesson 30 捣乱输入 B 同形状）
→ ④ D3 查询安检（内外同一套：只放行查看类语句 / 只认白名单表 / 按对方身份过滤数据行 / 强制限量——查询安检四件与 D3 `query-policy` 四开关同款，页面 RIGHTS ①–④；内外同权同闸＝F49 原句，无旁路）
→ ⑤ 执行与出门（同步结果带口径版本与出处；大结果以 voucher 句柄出门）
```

- 凭证页签（v0.1）签发的 Key 是外部调用面**唯一**鉴权凭证；`/api/expose/*` 全部端点（含清单读）都过此链。凭证轮换/停用立即生效（F61 纪律）：停用后新调用一律 401，已在途调用不追溯撤回。
- 每笔调用服务端自动更新该 Key 的 `lastUsedAt`（与凭证清单 `GET /api/keys` 的 `lastUsedAt` 字段同源）。
- **内外同权同闸、协议层不加权**（F28/F49/lesson 30 边界规则）：外部 Key 调用与内部用户过同一套安检，无协议侧特权通道——暴露清单=注册表可见性过滤的**同一函数同一结果**（lesson 30：外部只读档拿不到的，与内部无权角色拿不到是同一行代码）。

## 外部调用面 DTO 定义

### 1. GET /api/expose/config → 200

```json
{
  "mappings": [
    { "key": "tool", "way": "直接调工具", "maps_to": "内部工具注册表按可见性过滤后的清单",
      "endpoints": ["GET /api/expose/tools", "POST /api/expose/tools/{name}/calls"] },
    { "key": "ask", "way": "参数不够时反问", "maps_to": "平台既有缺参澄清问答",
      "endpoints": ["POST /api/expose/tools/{name}/calls（elicitation_required）", "POST /api/expose/elicitation/{elicitation_id}"] },
    { "key": "task", "way": "长任务给任务号", "maps_to": "异步任务队列：受理即回＋凭号取结果",
      "endpoints": ["POST /api/expose/tasks", "GET /api/expose/tasks/{task_id}"] }
  ],
  "allowlist": {
    "query_tools": true, "write_and_exfil": false,
    "statement": "查询类工具（查产量 / 查口径 / 查井档案）放行；写操作与外发类不在对外清单——写操作内部都要人工点批准，对外更不开放。"
  },
  "card": { "label": "打开平台名片", "url": "../agent-card.html", "kind": "static-page" },
  "security_ref": { "page": "D3", "note": "查询安检规则在 D3 安全与权限设置里配。" }
}
```

- `mappings[].way`/`maps_to`＝页面 WAYS 逐字照抄（合同值）；`endpoints`＝本合同新增的落位列（把映射位接到端点，管理页可据此展示"每个映射位走哪个接口"）。
- `allowlist.statement`＝放行清单口径全文（页面规格 §F9 原文；页面现实现以「对外状态」列头 ? 帮助承载缩略版——语义同源，见出入对账 4）；`query_tools/write_and_exfil` 两个布尔是**派生投影**（真源＝工具注册表的可见性过滤规则，与端点 2 同源），不设独立写入口——本版无"改对外配置"端点（放行口径变更属治理动作，走注册表可见性配置，不属 F1 页面）。
- **双主体同端点（与端点 2 同款）**：管理页「调用方式」页签走登录会话；外部 Key 调用走「调用鉴权链」全链（清单读不豁免）——本端点对外部调用方＝三映射位与放行口径的自我描述，无档位差投影。

### 2. GET /api/expose/tools?q= → 200

```json
{ "items": [ {
    "name": "按井查产量", "desc": "按井 / 区块 / 月查产油产液（审定口径）",
    "type": "查询 · 只读", "status": "已放行",
    "input_schema": { "required": ["井号", "月份"], "properties": { "井号": "井号 / 区块", "月份": "月份" } }
} ], "total": 3, "filtered": 3 }
```

- **清单＝内部工具注册表按可见性过滤的投影，现取不建仓、不建第二份拷贝**（页面列头 ? 原句："内部能用什么，外部就见什么，一件不多、一件不少——和内部用户同权同闸"；lesson 30 Tools 映射①：与 `tools_for` 同一函数同一过滤同一结果）。
- **双主体同端点**：管理页登录会话（阿强）＝完整对外清单视图（页面表格 4 列：名称/说明/类型/对外状态）；API Key 调用方＝同一清单与其档位求交后的子集（无权工具不在返回体——"世界里没有"，F48）。`input_schema` 两主体都返回（页面不展示、外部调用方据此构造 arguments）。
- `type` 枚举现值仅 `查询 · 只读`、`status` 现值仅 `已放行`（页面 3 行全同款）：写操作与外发类**结构性不在清单**（见行为规则 2），枚举为此留位但当前恒单值。
- `input_schema` 示例字段按页面示例请求参数组装（井号/月份）；运行时值来自注册表工具定义，**本合同不冻结具体字段集，只冻结判据**：缺必填＝`required` 检查（lesson 30 Elicitation 映射的闸就是 schema 判定）。
- `q`＝关键词筛选（匹配名称/说明；页面搜索框 `toolKw` 对应）；`total`＝清单总数、`filtered`＝本次筛选命中数（页面"筛选结果 N / 3 件"）。清单量大后加 `page/pageSize`（分页参数预留，C3 releases 先例）。

### 3. POST /api/expose/tools/{name}/calls → 200（三种收场）

入参 `{ "arguments": { "井号": "N-02", "月份": "2026-08" } }`（`arguments` 形状＝该工具 `input_schema`；**工具名不在清单内直接 404/403**，见错误码）。

**收场 A · 正常结果**（同步返回，自带口径版本与出处——页面 WAY_HELP"质检通过的数才出得了门"）：

```json
{ "status": "ok",
  "result": { "data": "产油量 1,4xx 吨",
              "caliber": "产量完成率口径 v3",
              "source": "汇总层日报表 · 质检通过" },
  "voucher": null }
```

`result.data` 形状随工具而定（示例值照抄页面调用示例）；`caliber`/`source` 两字段**必带**（页面示例返回三要素：数、口径版本、出处）。

**收场 B · 缺参反问**（Elicitation 映射：缺必填＝schema 判定，server-initiated 问询）：

```json
{ "status": "elicitation_required",
  "elicitation": { "elicitation_id": "el-7c2d", "tool": "按井查产量",
    "question": "缺一个必要参数——你要哪个区块？", "missing": ["区块"],
    "choices": [ { "value": "渤南", "label": "渤南" }, { "value": "渤中", "label": "渤中" }, { "value": "渤西", "label": "渤西" } ] } }
```

`question`/`choices` 示例值照抄页面反问示例；`choices`＝事实候选（渤南/渤中/渤西——区块为平台真实字段，设定书 §A.1），**不带默认项**："不做默认猜数"（页面脚注原句；缺的是调用方的事实，不是口径——对齐 A1 缺参反问类"无默认口径项"）。`missing` 示例值"区块"照抄页面反问问法——schema 槽位为 `井号`（"井号 / 区块"同槽，见端点 2 `input_schema`），判据仍＝`required` 检查。

**收场 C · 大结果句柄**（结果超行数阈值 → 正文不落数据，`voucher` 出门）：

```json
{ "status": "ok", "result": { "data": null, "caliber": "…", "source": "…" },
  "voucher": { "artifact_id": "art-9f2c7",
    "preview": { "columns": ["well_id", "prod_date", "oil_output(吨)", "water_cut(%)"],
      "rows": [ ["N-02", "2026-09-22", "48.10", "70.8"],
                ["N-11", "2026-09-22", "11.90（单位误录，质检问题单在办）", "87.3"],
                ["N-06", "2026-09-22", "0.00（注水井）", "98.2"],
                ["N-23", "2026-09-22", "23.45", "64.0"],
                ["N-37", "2026-09-22", "5.12", "91.5"] ],
      "total_rows": 31390,
      "numeric_summary": [ { "column": "oil_output(吨)", "min": 0.00, "max": 48.10, "mean": 17.71 },
                           { "column": "water_cut(%)", "min": 64.0, "max": 98.2, "mean": 82.36 } ] },
    "download_url": "…（GET 预签名，指向对象存储）", "expires_at": "2026-09-29T04:30:00Z" } }
```

- **voucher 形状＝A1 voucher DTO 同形**，本页不另立形状：句柄四字段＝`artifact_id` / `download_url`（GET 预签名）/ `preview.total_rows`（总行数随预览声明携带）/ `expires_at`（A1/F27 合同值）；`preview{columns,rows,total_rows,numeric_summary}`＝预览协议——5 行预览＋列名表头＋总行数声明＋数值列 min/max/均值摘要（F27 改注合同值）。预览行数上限 5 行（F27 预览协议）。
- `download_url`＝预签名 GET 直链、小时级签发、上限 7 天（F5 改注口径；A1 voucher / B1 端点 3 同族），**直链下载直达对象存储、不走平台转发**（B1 先例）；页面演示占位形 `/files/art-9f2c7?token=…` 为演示简写，真实形态结合实际框架定。
- 阈值与 A1 同源悬置（A1 开放问题 1：>50 行口径 vs D2「大结果行数阈值」配置）——**本合同只冻结出门形状**（凭证替代正文），阈值归属同 A1。
- 演示值注源：`art-9f2c7` / 31,390 行 / 约 0.9 MB / 86 口在产井 / 预览样本 5 行（N-02 48.10 · N-11 11.90 单位误录 · N-06 0.00 注水井 · N-23 23.45 · N-37 5.12，2026-09-22）与 min/max/均值行＝页面现实现 `F1.jsx` VOUCHER_PREVIEW/VOUCHER_FIELDS 照抄（演示数据；`art-9f2c7`/31,390 行与 A1 同源＝）；`expires_at` 演示值"2026-09-29T04:30:00Z（签发 2026-09-22 ＋ 7 天）"照抄页面。

### 4. POST /api/expose/elicitation/{elicitation_id} → 200（补参回流）

入参 `{ "choice": "渤中" }` → 返回与端点 3 **同形**（服务端把补参并入原调用上下文重判后继续执行；对齐 A1 澄清续跑"输入严格变多、非重复裁决"）：

```json
{ "status": "ok",
  "result": { "data": "渤中 2026 年 8 月产油 x,xxx 吨", "caliber": "口径版本 v3", "source": "出处见附" },
  "voucher": null }
```

## 外部调用面行为规则

1. **内外同权同闸（F49 原句保持，v0.1 规则 2 贯通全页）**：外部 Key 与内部用户过同一套 D3 查询安检（四开关/白名单/限量/按人过滤），协议层不加权、无旁路；拒绝帧与内部权限拒同形（不是"Key 无效"）。
2. **写与外发结构性不在对外清单（双锁）**：①清单锁——外部放行清单仅查询类，写操作与外发类不入清单（页面放行清单原文；agent-card capabilities 标签"外发通道: 无"同源；CONTEXT 外发闸/污染会话语义对内部会话生效，外部面直接以"不在清单"结构化排除）；②能力锁——F61 `write` 能力对外默认不授予（KEY_SCOPES 描述原文"对外默认不授予"）。两锁独立成立，破其一仍不可写。
3. **本体双通道边界（F49/CONTEXT）**：外部走**消费通道**——读对象、执行查询类工具；**管理通道（改类型/口径定义）不在外部调用面**——"外部对口径/术语只能提修改建议＋人工审批，而那条通道根本碰不到数据；日常这扇门能读、能执行动作，但改不了任何定义"（原句照抄页面规格 §F7 第二段；页面 RIGHTS 第 5 行为其缩略同义行——合同值）。外部修改建议的受理端点本版不立（开放问题 2）。
4. **只读档默认（agent-card authentication）**：外部 Agent 默认只读档、行权限随档注入——外部读到的数带审定口径与出处，不是原始表（页面 RIGHTS 第 6 行示例："上级单位的 AI 系统问'渤海油田本月递减率'——它读到的是审定口径的数，不是原始表"）。
5. **缺参不猜数、反问有界**：缺必填走 elicitation 反问（choices＝事实候选、无默认项）；最多一轮、两跳到终态；补参不免检（规则 1 贯通）。
6. **大结果以句柄出门（F27/设计稿 29）**：超阈值结果正文不落数据，voucher（句柄四字段＋5 行预览＋总行数＋min/max/均值）出门；落盘顺序闸（落桶→落库→签 URL）三步走完句柄才出门（A1/F27 合同值引用）；直链 TTL 小时级、上限 7 天。
7. **出口带口径与出处**：同步结果必带 `caliber`/`source`——质检通过的数才出得了门（页面 WAY_HELP 原句）；审计留痕同内部（外部调用也是审计事件）。
8. **演示数据零新增**：三种用法示例对话、对外工具 3 行、内外同权 6 行、行业复用 3 行、凭证示例卡全部值照抄页面 `F1.jsx`（WAYS/TOOLS/RIGHTS/REUSE/VOUCHER_*）与页面规格 §F1，逐条注源见各 DTO 节；`task-7c2d`/`el-7c2d`/`1,4xx 吨`/`x,xxx 吨`/口径 v3 为演示值。

### 7. GET /api/keys → 200（v0.1 保留）

```json
{ "keys": [ {
    "id": "ak-9f2c7a", "name": "上级单位 · 数据报送",
    "scopes": ["context", "query"], "fullAccess": false,
    "createdAt": "2026-08-27T10:00:00", "lastUsedAt": "2026-09-28T19:34:00",
    "status": "active | rotated | revoked", "hint": "pa-****9f2c"
} ] }
```

- **永不回明文**；`hint` 为脱敏占位。`status`：active 启用中 / rotated 已轮换（旧 Key 失效留痕）/ revoked 已停用（终态）。
- v0.2 贯通注记：`lastUsedAt` 的更新源＝`/api/expose/*` 外部调用（见「调用鉴权链」），字段语义不变。

### 8. POST /api/keys → 201（v0.1 保留）

入参 `{ "name": "上级单位 · 数据报送", "scopes": ["context","query"], "fullAccess": false }`

- 校验：`name` 必填；**非 full-access 时 `scopes` 至少一项**（400）——"全不勾＝什么都干不了"，不允许签发哑 Key 造成"以为有权限"的错觉。
- `fullAccess=true` 时忽略 `scopes`（等效全能力），**签发操作要求治理角色**（403）。
- 返回 `{ "key": {…同上…}, "plaintext": "pa-live-…" }`——**服务端只存指纹，明文不落库、仅此一次返回**；前端一次性展示（关闭后只显示 hint）。

### 9/10. 轮换与停用（v0.1 保留）

- `rotate`：仅 `active` 可轮换（409 对已停用/已轮换操作）；旧 Key 置 `rotated` 立即失效，新 Key 继承 name/scopes/fullAccess，返回新明文一次。
- `revoke`：仅 `active` 可停用；置 `revoked` 终态立即失效。

### 凭证页签行为规则（v0.1 保留）

1. **默认拒绝（fail-closed）**：scoped Key 未声明的能力一律 403，拒绝帧与内部权限拒同形（不是"Key 无效"）——W 语义对齐 m8 `Permission.assert_allowed`。
2. **内外同权（F49 原句保持）**：外部 Key 调用与内部用户过同一套 D3 查询安检（四开关/白名单/限量/按人过滤），无旁路。
3. **明文纪律**：明文只在签发/轮换响应中出现一次；服务端仅存指纹（摘要）；页面轮换/停用均立即生效。
4. **A2A 名片同步**：`agent-card.html` authentication＝"服务账号＋API Key（scoped，未声明默认拒绝）；外部 Agent 默认只读档"。
