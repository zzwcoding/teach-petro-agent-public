## DTO 定义（关键形状）

### 2/3. 查询策略

```json
{
  "switches": [
    { "key": "readonly_only | table_whitelist | row_limit | row_filter",
      "name": "只放行查看语句", "desc": "…", "enabled": true }
  ],
  "defaultLimit": 50,   // 可改，1–200
  "maxLimit": 200       // 合同上限（PRD F14），只读
}
```

红线：LIMIT 没写补 defaultLimit、超 maxLimit 截断，**只封顶不抬底**（W-F14-1 的 mandatory filter 依据）。

### 4. 表白名单

```json
{ "denyDefault": true,
  "tables": [ { "cn": "日产计量", "en": "oil_production_daily", "note": "…",
                "usedBy": ["工具·按井查产量", "工作流·产量下滑归因"] } ] }
```

`usedBy`＝引用方可见性（吸收 WeKnora 删除前占用预检语义：改白名单前先看谁在用）。白名单增删不在本页直改——走 C3 审批（本批接口只读）。

### 5/6. 出站策略

```json
{ "defaultWhenTainted": "deny",
  "channels": [ { "id": "send_report", "tool": "send_report",
                  "target": "data-report.cnooc.bs", "what": "…",
                  "registered": true, "credentialHint": "sk-****" } ] }
```

- 语义固定：**会话含外部资料（被污染）时外发默认拒绝；`registered=true` 的通道例外放行**（W-F16-2：污染会话调 invoke_api → deny，数据零外发）。
- `credentialHint` 只回脱敏占位；**编辑提交占位值＝保留旧凭据**（WeKnora 语义吸收）；密文存储在服务端。

### 7–10. 沙箱执行

- 限额（只读）：`{ "maxRows": 50000, "memoryMb": 512, "wallSeconds": 60, "onReject": ["降级估算并标注\"估算口径\"", "留白拒答"], "runtimeNote": "…" }`——**合同值，接口也不提供直改**。
- `POST sandbox-runs` → `{ "runId": "run-1043" }`；重入 409。
- 轮询返回：`{ "status": "running|done", "nodes": [ { "key", "label", "state": "wait|process|finish|error" } ], "result": … }`
- `result.rejected`＝**sandbox_denied 三字段**（F57 合同）：

```json
{ "gate": "读入行数上限（50,000 行）",
  "trigger": "已读 50,000 行（本次任务共 131,000 行）",
  "disposal": "容器终止销毁——部分结果绝不冒充完整结果" }
```

- **done 时服务端落试跑历史**（时间/剧本/触发闸/处置/on_reject）——拒绝留痕成为可查审计数据；历史接口倒序分页。
- **容器出站默认隔离不立合同形状**（F57 扩条目②，2026-09-28）：沙箱容器网络层默认断外网、放行清单与 F16 工具层白名单同源——纵深防御的"能不能连通"兜底属部署层规则，PRD 原文"落地形态结合实际框架定"，故不入本合同 DTO（`runtimeNote` 自由文本承载演示文案）；工具层"该不该外发"判据＝端点 5/6 出站策略（F16 合同）。

### 11. 权限矩阵

`{ "layers": [ { "key": "context|query|compute|write|governance", "name", "nick", "help" } ], "roles": [ { "key", "name", "badges": ["ok|none|constrained|partial|owner|final" ×5], "detail": [ [ { "t": "文本段" } | { "a": ["#/A2", "链接文字"] } ] ] } ] }`

五层与徽标语义是 F48 合同（W-F48-1/W-F48-2：没配＝结构上没有入口）。矩阵写操作（逐格授权）不在本批，未来扩展 `PUT /permission-matrix` 时同样走 C3。

### 12–14. 加密与密钥、留痕

- `crypto-fields`：字段/位置/加密方式/密文样貌（m11 SM4 口径）。
- `key-selfcheck` → `{ "ok": true, "checkedAt", "checks": [ { "name": "主密钥在位|密文抽检可解|摘要校验通过", "ok", "message", "latencyMs" } ] }`——**失败也是 HTTP 200，必须查 `data.ok`**（WeKnora sandbox-check 语义吸收）。
- `audit-logs`：`{ "items": [ { "time", "who", "action", "digest" } ], "total", "page", "pageSize" }`——digest＝SM3 摘要指纹，**永不落正文**（m1 `request_log`）。

## 错误码草案

| 场景 | HTTP | 说明 |
|---|---|---|
| 限量越界 / 开关缺失 | 400 | 错误体带字段与允许区间 |
| 未认证 / 无权 | 401 / 403 | 设置中心组=运维角色 |
| 试跑重入 | 409 | 已有试跑进行中（前端按钮禁用兜底） |
| 写操作未过 C3 | 422 | 受理但被安检驳回，错误体带驳回理由（fix_hint 语义，W-F14-6） |

## 与 WeKnora 对标的取舍记录

- **吸收**：出站策略"默认拒绝+白名单例外"模型、凭据脱敏/占位保留旧值、check 分项+latency 展示、删除/变更前占用可见性（usedBy）、拒绝与操作全量留痕。
- **不采纳**：沙箱交互终端与一次性票据（我方沙箱跑审批剧本，无人工终端）、技能 ZIP 自装与灰度（工具=Owner 审批资产）、多沙箱后端类型（国产化单一运行时，F11）。
- **合同值不动**：50/200、50,000 行/512MB/60 秒、gate/trigger/disposal、四级信任、五层矩阵、SM3/SM4。

## 权限矩阵设计稿（RBAC——P1-00b 设计先行批，2026-10-01，只设计不实现）

> 背景拍板：阶段 1 单一角色「系统管理员」全权、所有写功能照做；本设计稿是未来分权的设计图纸——**设计先行、实现预埋、落闸后分**（Owner 2026-10-01）。本节是设计产物非端点合同，端点形状零变更（v0.1 不升版）。

### 模型：RBAC 三件套

- **权限点＝资源:操作，粒度＝合同端点**——如 `kb:lib:create`＝`POST /api/kb/libs`、`faq:entry:publish`＝B3 端点 17、`graph:config:save`＝B5 端点 3。D3 权限矩阵＝「端点 × 角色」勾表：**底表由 21 册端点清单自动生成**，端点新增必须同步矩阵行（对账进 CI，漏行即红）。
- **角色＝权限点集合；用户＝角色指派**（一用户可多角色，有效权限＝并集）。
- **五角色初稿**（待 Owner 过目冻结）：系统管理员（owner 全量）｜阿强·平台运维（设置中心组＋D1/D2＋安全审计读）｜小李·地质（工作台全读＋报告上传＋FAQ 维护）｜核查员（切片标记＋复核队列）｜老王（查询消费面只读）。

### 执法位置：服务端统一校验，deny-by-default

- **唯一执法者＝服务端**：每个端点声明所需权限点（FastAPI dependency 形态：`require("kb:lib:create")`），**未声明＝拒绝**（deny-by-default，绝不由"没声明"滑向放行）；校验通过即注入身份上下文，业务层零散落判权。
- 越权尝试一律 **403 `security_forbidden`** 且必走 B12 审计写口（who／端点／所需权限点／所持角色）。
- 现状组闸（PageGroup 六组）＝本设计的粗粒度前身；**D3 落闸批切换时组闸退役**——替换只动 `security.resolve_actor`/`authorize` 实现（身份桩替换同款缝，ADR-0003），接口层与业务层零改动。
- **前端只按权限渲染**（菜单/按钮隐藏或置灰，权限随身份读口下发），不做真闸——防裸 curl，服务端才是墙。

### 数据与时间线

- 表（99 册随 D3 落闸批建）：`sys_user`／`user_role`／`role`／`role_permission`／`permission`——sys_user 随阶段 2 D3 整页票落库（B1 开放问题 1 同族口径）。
- **时间线**：阶段 1＝本设计稿＋每端点权限点声明预埋（实现成本≈一行/端点，各票顺手）；阶段 2＝sys_user＋落闸切换（组闸退役）；阶段 4 前＝OAuth2.0 替换 `resolve_actor`（真身份上线，F1 对外前提）。
