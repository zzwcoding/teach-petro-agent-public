## 页面定位（先于端点的合同常量）

**一口井一份档案**：档案明细（井号/井名/井别/投产/平台/区块/状态/备注＋质量备注红字）＋关系链五页签（纪录/措施/设备/检修/变动）。页面定位＝**井的档案**——**产量统计不落档案页**（拍板 2026-09-27："生产数据统计和问答平台是两个东西，这里更关心井的档案"）；要问数、要分析，行尾一键"去问一问"。**本合同因此不设任何产量统计/趋势端点**；问数与专业函数（F46 `calculate_decline_risk` 递减风险等）全部经 F4 由 A1 四层流水线承接。

| 页面功能 | 端点承接 |
|---|---|
| F1 选井切换与档案明细 | 端点 1（选井列表）＋端点 2（档案明细） |
| F2 关系链五页签（纪录/措施/设备/检修） | 端点 3（关系链：合并纪录＋三台账＋计数＋尾注） |
| F3 变动回链（变动页签） | 端点 4（涉及本井的变动单投影——主单在 A3） |
| F4 去问一问 | **不立新端点**——跳转 A1，复用 `POST /api/chat/asks` 的 `page_context`（见「去问一问」节） |

## DTO 定义（关键形状）

### 1. GET /api/wells → 200

```json
{
  "items": [
    { "well_id": "N-02", "well_name": "渤中28-1-N2", "well_kind": "采油", "well_kind_code": "EW",
      "block_name": "渤南", "current_status": "生产中", "remark": "正常" },
    { "well_id": "N-06", "well_name": null, "well_kind": "注水", "well_kind_code": "IW",
      "block_name": "渤南", "current_status": "生产中", "remark": "分层注水（3 层）" },
    { "well_id": "N-11", "well_name": null, "well_kind": "采油", "well_kind_code": "EW",
      "block_name": "渤中", "current_status": "停产", "remark": "2026-08-30 起检泵" }
  ],
  "total": 3
}
```

- **行级权限过滤在服务端**：`items` 已按当前角色数据域裁剪——无权限的井不在响应里（F48"看不到=世界里没有"），前端不做打码也不做二次过滤。演示种子三井（N-02/N-06/N-11）对全员可见；真实示例：角色数据域＝渤南时 N-11（渤中）不出现——数据域授权管理归 D3（`GET /api/security/permission-matrix`）。
- 排序按 `well_id` 升序；下拉 option 文案（「N-02 渤中28-1-N2（渤南 · 采油 · 生产中）」等）为前端展示层拼装，演示文案照抄页面规格——末段取当前状态或备注属展示层选择（N-06 用备注「分层注水 3 层」，N-02/N-11 用状态），所需字段响应均已携带；**禁用占位条目「（无查看权限的井不在此列表）」为前端常量提示，不入响应**。
- `well_name` 空缺（N-06/N-11 设定书样本未给井名）以 `null` 返回，页面渲染"—"（照抄页面）。

### 2. GET /api/wells/{well_id} → 200（档案明细）

```json
{
  "well_id": "N-11", "well_name": null, "well_kind": "采油", "well_kind_code": "EW",
  "first_prod_date": "2020-02-20", "platform": "CEP-B", "block_name": "渤中",
  "current_status": "停产", "remark": "2026-08-30 起检泵",
  "quality_notes": [
    "台账状态\"停产\"与产量表 9-14 仍有开井 6.5 小时记录并存（状态滞后，已提示数据岗）。",
    "产量表单位误录：9-14 日产油 12.40\"方\"（按渤中密度 0.89 t/m³ 折算 ≈11.04 吨，已提示数据岗）。"
  ],
  "foot_note": null
}
```

- **8 字段对应**：井号=`well_id` / 井名=`well_name` / 井别=`well_kind`＋`well_kind_code`（展示拼装「采油（EW）」）/ 投产=`first_prod_date` / 平台=`platform` / 区块=`block_name` / 状态=`current_status` / 备注=`remark`（跨 2 列）。字段名对齐设定书 §A.1 `well_info`（first_prod_date/block_name 原名沿用）。
- 状态 Tag 颜色（生产中绿/停产红）为展示映射；井状态值域＝合同常量四枚举（设定书 §A.1）。
- `quality_notes`：**红字质量备注，文本数组逐字照抄页面**，仅 N-11 有（两条：状态滞后 / 单位误录；其余井为空数组，前端不渲染红字块）。来源锚点：①状态滞后＝设定书 §A.1（current_status 状态滞后脏特征）× §A.2（9-14 开井 6.5 小时矛盾行）；②单位误录＝设定书 §A.2（`12.40方` 样本行）× §2.2 单位换算表（渤中 0.89 t/m³）× §4 规则 3（单位一致性）。**与 E2 数据质量台同源**：质量问题的主单与整改流转在 E2（`GET /api/quality/issues`），本页只读展示该井维度的摘要——井维度关联字段待 E2 批对齐（跨页锚点，见开放问题 2）。
- `foot_note`：卡底灰字注记，服务端按井别派生——注水井（IW）＝「注水井无日产油记录，"产量最高"类排名自动排除本井。」（照抄页面；"产量最高"类排名指 A1 问数场景的口径排除），采油井＝`null`。mock 的 DEV 模式工程注记『（m16 对象关系 · W-F45-1）』属 `?dev=1` 调试层（P-1 工程注记退出页面），不入合同。

### 3. GET /api/wells/{well_id}/chain → 200（关系链）

```json
{
  "well_id": "N-02",
  "counts": { "events": 6, "measures": 5, "devices": 2, "overhauls": 1, "changes": 4 },
  "measure_types": ["压裂", "酸化", "补孔", "调剖"],
  "device_types": ["电泵", "螺杆泵", "加热炉"],
  "measure_foot": "措施类型枚举：压裂 / 酸化 / 补孔 / 调剖",
  "device_foot": "设备类型枚举：电泵 / 螺杆泵 / 加热炉",
  "events": [
    { "key": "m1", "kind": "措施", "date": "2026-03-18", "title": "调剖 · 主力层段调剖，调整吸水剖面",
      "outcome": "综合含水降 1.2 个点" },
    { "key": "o1", "kind": "检修", "date": "2024-10-09", "date_end": "2024-10-11",
      "title": "检泵（泵轴更换）", "outcome": "影响产量约 18 吨 · 批次 20241012-T2" }
  ],
  "measures": [
    { "key": "m1", "date": "2026-03-18", "type": "调剖", "content": "主力层段调剖，调整吸水剖面", "result": "综合含水降 1.2 个点" },

    { "key": "m4", "date": "2023-04-20", "type": "压裂", "content": "主力层重复压裂", "result": "日增油约 8 吨，递减较快" },
    { "key": "m5", "date": "2022-08-15", "type": "调剖", "content": "笼统注水条件下调剖", "result": "综合含水降 0.8 个点" }
  ],
  "devices": [
    { "key": "d1", "type": "电泵", "status": "运行中", "since": "2021-04-12", "note": "2021 年换泵更新；上次保养 2026-06-02" },
    { "key": "d2", "type": "加热炉", "status": "运行中", "since": "2019-09-01", "note": "冬季高负荷、夏季低负荷" }
  ],
  "overhauls": [
    { "key": "o1", "date_start": "2024-10-09", "date_end": "2024-10-11", "job": "检泵（泵轴更换）",
      "impact": "影响产量约 18 吨", "batch": "批次 20241012-T2" }
  ],
  "tail": null
}
```

- **`counts`（五页签计数，随井联动）**：`events`/`measures`/`devices`/`overhauls` 为本端点各数组的长度；**`changes`＝变动页签计数，与端点 4 的 `total` 同源同值**（服务端内部关联 A3 主单取得，前端零拼算）。
- **`measure_foot`/`device_foot`（措施/设备页签的枚举尾注全文，随井）**：服务端按井派生的展示字符串——通版＝「措施类型枚举：压裂 / 酸化 / 补孔 / 调剖」「设备类型枚举：电泵 / 螺杆泵 / 加热炉」，随井前缀变体见下节（N-06 措施尾注带「注水井措施以调剖为主」、N-11 设备尾注带「检泵作业对象＝抽油设备」）；页面尾注以 foot 全文渲染，前端不自行拼装业务文案。`measure_types`/`device_types` 为尾注枚举段的结构化字段（合同常量值域，恒返回），供非展示消费。
