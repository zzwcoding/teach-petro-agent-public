## 页面定位（先于端点的合同常量）

**本页管数据从进门到能被问数的全程**（页头 ? 悬浮原文照抄，页面为四条「·」行）：接入：8 个源一律原样入库——端到端血缘，报表上一个数对不上，能一路指回原始文件的某一行。清洗：规整表格自动识别 / 嵌套炸开 / 扫描件识别＋人工复核，三条路。加工：原始 → 清洗 → 汇总（星型模型）；问数只认汇总层就绪的大表。表→业务对象映射与增量更新口径也在这里配。页头定位行（照抄）＝「**先原样进来不改一个字 · 三条路洗净 · 拼成问数直接用的大表**」。页面现实现为六页签：**接入源（8）／清洗路径（3）／三层加工（3）／对象映射（4）／增量与风险（2）／效率账（3）**——页签名与计数照抄；**效率账页签＝ 设计增补（规格 §D6 未收录），判定为纯静态设计资产、不入本合同**（出入对账 1）。

5. **增量语义**：每天只加工新到的行、对象档案只更新变化的部分不整表重刷；坑一按批次取最新不混用、坑二先查到账批次不先怀疑数错（见「增量策略与两坑」节）。
