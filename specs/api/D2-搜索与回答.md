## 引用格式切换语义（关键合同裁决——A1/B2 锚点兑现）

**cN 别名机制是生成链恒定底座，本开关只切"回答正文里引用的呈现格式"**：

1. **生成链不回退**：模型上下文恒为低熵别名 cN、输出经服务端流式展开、**未知别名 fail-closed 直接删除**（F33/W-F33-1…2；B2 合同"引用号对不上的一律删掉、不渲染"同口径）——**不因选格式一而改变**。防伪造（格式二徽标语义）由 cN 机制恒定保障，与格式选择正交。
2. **开关切的是呈现层**：`citationFormat=page` → A1 答案正文角标与引用按 `[报告名 p.页码]` 展开（`citation` 帧的 `label`/`locator` 携带报告名与页码——人读友好）；`citationFormat=code` → 正文按 `[cN]` 编号呈现、真实出处收敛进"本轮引用清单"面板（答完再展开——F33 的引用清单恰好承载，页面格式二示例"答完再展开成真实出处"）。
3. **A1 合同零变更**：`citation` 帧 DTO `{ref:"cN", kind, label, locator}` 形状不变（A1 已冻结）；A1 前端按生效 `citationFormat`（本页端点 1 为权威源）渲染角标与清单——`locator` 三件套（report/well/section，B2 互检同形）两格式共用、B2 片段台账不受影响；格式 page 的页码走 `locator.page`（报告引用族扩展件——B2 合同已注 locator.page 为扩展、片段台账不冻结页码）。
4. **切换发版时机**：变更申请 → A3 批准 → C3 安检通过后随语义版本发布发版生效；**发版后新提问按新格式渲染，历史答案保持原格式**（A1 会话/消息回放只读原样——A1 端点 3）；在途 run 不重渲染。
5. **两读声明已关单（Owner 2026-10-01）**：PRD F33"既有 `[报告名 p.页码]` 格式保留为对照选项"的两读（展示层对照 vs 模型上下文层回退直写报告名）——**维持展示层裁决**（依据 1；PRD F33 已加增补注记同源），生成链恒走 cN+fail-closed、不回退上下文形态。
