## 页面定位（先于端点的合同常量）

报告的**可读版**：把入库切好的段拼回全文（重叠去重、图片说明回读），再按 wiki 模板重写成**一篇自由 Markdown 文档**——小节标题、段落、表格、列表由内容自由长出（模板约束在生成提示词里、不设固定节 schema，见「wiki 模板语义」节）；页面＝**元数据条＋自由 markdown 正文**：元数据条（紧凑、可展开）承载来源报告（链 B1）／生成来源／当前版·更新于·操作人／状态／slug，展开区另有所属库与**关联对象**行（井对象卡收编于此，链 A2 井档案／B5 关系图谱）；正文内嵌论断证据锚 `[证]` 角标与台账挂接 chip（虚线下划线词，点开口径卡）。**v0.4 起每次重建覆盖当前版**——不留历史版本、不回滚（Owner 2026-10-04 拍板撤除版本治理）。页头定位行（照抄页面，v0.4 改版同步）＝「**报告入库自动重写成中文百科页 · 页内词条自动挂链接 · 与井档案对不上自动标出**」。页面形态（v0.4）：**两页签**——**百科页**（目录——每库百科页总账＋筛选）、**页面内容**（元数据条＋markdown 正文）；版本历史页签随 v0.4 撤除。

## wiki 模板语义（v0.4——版本治理撤除登记）

- **模板＝提示词约束，不在 schema（v0.3 改版核心裁决，v0.4 不变）**：wiki 页产出**自由 markdown 全文**（content TEXT 形态——固定元数据列＋自由正文列），固定节（摘要卡/关键参数表/表格摘录/对象卡）撤除；模板只活在生成提示词里（按库 WikiConfig 配置提示词取向），**不设固定节 schema**。注源：WeKnora `prompts_wiki.go` 先例（wiki 生成＝按模板出提示词、正文自由 markdown 落库）＋ PRD F50「重写成 Markdown 页」原语义；F50 注记随本批增补。
- **版本治理撤除（v0.4——Owner 2026-10-04 拍板"版本历史直接去掉不要了"）**：原 v0.3「版本三件套」（版本列表／查看任意版全文 `?version=N`／一键回滚）**全部撤除**——端点 3（版本列表）、端点 4（回滚）删端，端点 2 撤 `?version=N`；每次重建**覆盖当前版**，不留历史、不可回滚。撤除理由（Owner 裁决）：无消费者（问答不走百科页、当前单人使用场景不读版本历史）＋治理功能无验收标准；原 diff 撤除登记（v0.3）随之整体失效。**人工编辑场景**（开放问题 1）裁决不做——F51"可人工编辑"出入登记见出入对账 11。百科页内容纠错走"修源头报告→重新入库→重铸覆盖"路径。
- **修订提示行（红标的新形态，v0.4 不变）**：与井档案对不上的内容**不另起红标卡片区**——以正文内嵌修订提示呈现（`[[flag:<提示文本>]]` 标记，渲染为句中黄底高亮「⚠ 与井档案不符，待核对」）；flag 生成时固化，随重建重新核对重新生成（覆盖语义下无"回滚到无 flag 版"路径）。

## 与 B1 的生产/消费边界（主单合同，先于端点清单）

## 论断回链（F52 落位——Owner 2026-10-01 拍板，先于端点清单）

- **语义**：wiki 页生成时，页上的论断（参数值/结论句/表格行）携带**证据锚**——锚到生成它的切片（B2 片段 id 同域，f1–f8 锚资格已由 B2 合同冻结）；正文文流中论断后渲染 `[证]` 角标，点击定位来源片段——知识层↔证据层闭环（F52「页上论断可回链证据块」原语义，开放问题 5 据此落位）。
- **证据锚结构**：`claim → evidence_chunk_ids` 列表——一论断可多锚；论断与锚在**生成时固化**（v0.4＝随重建重新生成、覆盖当前版快照）。v0.3 起锚在正文中的**位置**以 `[[claim:<claim_id>]]` 标记承载（content 字段内，`links` 固定区形态随之撤除）——claims[] DTO 不变。
- **DTO**：端点 2 增 `claims[]` 段（随 v0.2 生效，形状见端点 2）：`{ "claim_id": "w1-c1", "text": "<论断句/参数行/表格行文本>", "evidence_chunk_ids": ["f1", …] }`——`claim_id` 页内唯一；`text`＝论断原文（页上渲染句的纯文本投影）；`evidence_chunk_ids`＝B2 片段 id 列表（空列表＝无锚论断）。

- **证据弹层**：点 [证] 弹证据来源层（切片 id/类型/报告/章节路径/原文句）——数据＝B2 端点 1/2 形状（`report`/`section`/`type`/`hit`＋`context`）的只读投影，服务端组装（前端零拼装业务文案，行为规则 5 同纪律）。
- **fail-closed 口径**：锚失效（chunk 重建后 id 不存在）/ 无锚论断 → **不渲染 [证]、不伪造回链**——宁可少显示、不错挂锚（F33 cN fail-closed 同族纪律）。

## 台账挂接（F51 增补落位——Owner 2026-10-01 拍板，先于端点清单）

- **语义**：wiki 正文里的术语/指标自动识别并挂 C1 卡——点开看定义/状态/有效期（卡片弹层，企业腔口径）。
- **识别词表＝C1 台账名册＋别名**：端点 2 术语名＋端点 3 `slot_name`（指标名剥法后的槽位纯名）投影；**台账没有的词不挂**（防误链——F51 单字不挂链同族、台账闸思想）。示例：正文出现「综合含水率」挂（名册有），裸词「含水率」**不挂**（名册无此词）。

## DTO 定义（关键形状）

### 1. GET /api/wiki/pages → 200

入参 `lib=all|完井报告库|生产月报库`（页面下拉"所属库：全部/完井报告库/生产月报库"）· `keyword=<百科页题名/来源报告/所属库模糊>`（页面搜索框 placeholder「搜百科页 / 来源报告…」；mock 匹配 title+src+lib 三字段，合同冻结三字段模糊）。

```json
{
  "items": [
    { "id": "wiki-n02-completion",
      "title": "《N-02 井完井报告》",
      "lib": "完井报告库",
      "source_report": { "id": "rpt-n02-completion", "doc": "《N-02 井完井报告（英文 · 200 页）》" },
      "current_version": 3,
      "updated": "2026-09-20",
      "status": "字段待核对" },
    { "id": "wiki-bz281-monthly-202608",
      "title": "《渤中28-1 区块月度生产月报》",
      "lib": "生产月报库",
      "source_report": { "id": "rpt-bz281-monthly-202608", "doc": "《渤中28-1 区块月度生产月报（2026-08）》" },
```

- 两页演示词条照抄页面 PAGES（题名/所属库/来源报告名/最近更新全照抄）——`title`＝PAGES 原值**不带「百科页」后缀**：read 页头「{title} · 百科页」的后缀与目录行「来源：{src}」副行由前端拼装（页面规格词条写法「《…》百科页」含后缀，以页面现实现为准——出入对账 1 同族）。`id`＝本合同新造演示 slug（wiki-*；slug 稳定性的载体，重解析原地复用）；`source_report.id` 与 B1 台账报告 id 同域（`rpt-n02-completion` 已在 B1 冻结；月报行 id B1 未逐行冻结——接线批对齐）。
- `updated`＝当前版（最近一次重建）的更新时间（服务端派生，非独立字段）；`current_version`＝**重建计数**（v0.4——单调 +1，无版本历史语义；页签计数与元数据条"当前版 vN"按此渲染）；**与 B1 台账 `wiki` 字段同源**（见生产/消费边界节）。
- `status` 按当前版红标字段有无判定（合同常量表）；修源头重入库重铸后重新核对翻状态。
- 演示目录仅两页、**制度文件库未出百科页为演示缺省不洗白**（其 B1 库配置 wiki 开关＝开，真实系统按生成结果返回）。
- `total`＝全量计数；"筛选结果 X / Y 条"＝前端按 items 长度＋total 拼（C3 counts 同款，不另设字段）。
