> **三档是选项制同场对照，不是三选一强推（CONTEXT.md 词条"选项制"）**：重排档**按库配置三选一**（四开关/兜底策略同款配置家族），**缺省=模型档**——此时管道行为与设计稿 10 升级前逐字一致（**反断言**：`rerank_composite` 模型档分支就是对既有 `rerank` 的原样委托，零新增判断）。三档各答一个场景：延迟敏感→模型档（1 次批量精排调用）；精度优先不怕贵→LLM 档（逐候选换更强匹配范式）；多样性敏感→复合档（复合分加权+MMR 选样）。三档**输出形状同一**（都是 `Ranked`），生成侧与引用侧对"这一轮走了哪档"零感知——档位是 Ranker 内部事，不外溢。
> **成本边界（设计范围边界红线，评审合同）**："只重排融合池前 N（成本账成文）；不重排全部召回"落成两条结构位：①候选入参**已是融合池前 N**——设计稿 10 既有"RRF 全量融合后先截前 20 再进精排"的两级截断位（设计稿 10 主干三取舍表），`rerank_composite` 不回读全部召回、无全量入口（主干一①）；②**成本账成文**（主干一②对照表）：模型档=1 次批量精排调用；LLM 档=**N 次生成调用（调用计数=N，W-F34-2 判据本体）**，逐次走 m2 网关记账（设计稿 07 既有面）；复合档=1 次批量精排调用+MMR 纯本地分词比较（零模型调用）。
> **检索基础分的刻度（签名纪律，不发明公式）**：复合分第二项 0.3×检索基础的输入**不是 RRF 原始分**——k=60 的 RRF 分数量级仅 ~0.03，乘 0.3 后在复合分里失声，权重等于白给；落定：前 N 内**位次归一**到 [0,1]（第一名 1.0、末位趋 0，纯内部相对刻度）。WeKnora 同构实测：单路结果进重排前 `rescaleUnboundedScores` 折算到 [0,1]，注释原话"Raw BM25 (often >10) saturates compositeScore's 0.3*base term"（`knowledgebase_search_fusion.go:41-43`）——**同一动机**（0.3×base 项要有可比刻度），WeKnora 折单路无界分、本设计稿折前 N 位次，取舍 2 备案。
> **接线边界**（对既有设计稿只调用不重讲）：对设计稿 10 **只加不改**——双路召回/RRF 融合/`Ranker.rerank` 签名与函数体全部保留，本节在 Ranker 上**新增并行公开签名** `rerank_composite`（模型档分支原样委托 `rerank`，反断言见上）；设计稿 10 的无据拒答闸判据（候选空或全低分）零改动，复合档输出的 `Ranked` 仍走同一闸——**阈值是每档各自的标定物**（换档=换刻度，生成侧判据形状不变，取舍 4）。对设计稿 47 **分工衔接不重讲**——复合档阈值族挽回失败后的"全空信号"落到设计稿 47 既有 `answer_or_fallback` 分岔位（候选空判据已含），本节零触碰其函数体；对设计稿 07 **零接触**——LLM 档逐候选打分调用照走网关既有面（别名路由/记账/重试），N 次调用逐次记账是既有 spend 面的自然累加；对设计稿 46 **只读其产物形状**——融合池候选自带 chunk_type 标（设计稿 44/46 行族字段），为 FAQ 加成（设计稿 49）与 Wiki 加成留判定位但本节零展开。

### 主干一：rerank_composite——三档分派与成本边界（设计范围边界红线 + 各档入口）

```text
伪代码 — app/rag/ranker.py:Ranker.rerank_composite（卡 m6 公开签名逐字：
         rerank_composite(query, candidates, top_n) -> Ranked；卡面注释
         "重排三档选项：bge 模型分（既有）/ LLM 逐一打分（换范式非补救 RRF）/
         复合分 0.6×模型+0.3×检索+0.1×来源 + MMR λ=0.7（F34）"是本函数的结构合同）

def rerank_composite(self, query, candidates, top_n) -> Ranked:
    # 主干判断①边界闸：candidates 已是融合池前 N（设计稿 10 两级截断位的产物）——
    #   本函数无全量入口、不回读召回层（设计范围边界红线"不重排全部召回"的落点）；
    #   空候选短路：直接返回空 Ranked（生成侧无据拒答闸的既有判据原样接住）
    if candidates 为空:
        return Ranked(候选=[])
    # 主干判断②三档分派（按库配置三选一——四开关/兜底策略同款配置家族；
    #   缺省=模型档）：
    if self.重排档 == "模型档":
        #   反断言：模型档=既有 rerank 原样委托——签名与函数体零改动，
        #   行为与设计稿 10 升级前逐字一致（本节新增的是并行签名不是改写）
        return self.rerank(query, candidates, top_n)      # 既有签名按字引用（设计稿 10 地盘）
    if self.重排档 == "LLM档":
        return self.逐候选打分(query, candidates, top_n)   # 主干二——N 次调用计数=N
    # 复合档：打分（模型分批量 1 次调用）→ 复合加权 → 阈值族 → MMR 选样
    打分对 = [[query, 候选.清洗正文] for 候选 in candidates]
    模型分列 = _reranker.compute_score(打分对, normalize=True)   # 既有调用形状（设计稿 10 主干三）
    加权列 = 复合加权(candidates, 模型分列)                      # 主干三①②③——拆账在此
    过阈列 = 阈值族(加权列)                                     # 主干三④⑤——fallback 在此
    return MMR选样(过阈列, top_n, λ=0.7)                        # 主干四——W-F34-3 本体
```

**成本账成文（设计范围边界红线②，W-F34-2 前半句的对照面）**——三档调用次数与延迟形状，按前 N=20 计：

| 档 | 模型调用次数 | 调用面 | 延迟形状 | 适用场景（PRD 选项矩阵第 6 行） |
|---|---|---|---|---|
| 模型档（缺省） | 1 次批量精排调用 | m6 既有 `compute_score`（一次吃 20 对） | 最短 | 延迟敏感 |
| LLM 档 | **N 次生成调用（计数=N）** | m2 网关既有面，逐次记账（设计稿 07 spend 面） | ≈N×单次（逐候选串行设计演绎） | 精度优先不怕贵 |
| 复合档 | 1 次批量精排调用 + 零模型调用的 MMR | 同模型档 + 本地分词/比较 | 模型档+本地计算 | 多样性敏感 |

### 主干二：LLM 打分档——N 次调用计数与解析失败回退原序（W-F34-2 本体）

```text

def 逐候选打分(self, query, candidates, top_n) -> Ranked:
    # 主干判断①逐候选一条打分提示（W-F34-2 走查列"对前 N 逐一发打分提示"——
    #   每候选独立一问：问题+该候选清洗后正文，只要一个 0–1 相关性分；
    #   走 m2 网关既有面逐次调用，spend 记账自然累加——调用计数=N 的账就记在这）

            #   链路照常走完（"不炸链"的形状：返回值仍是 Ranked，只是序=原序）

    排序列 = 按分数降序(原序, 分数表)
    return Ranked(候选=排序列[:top_n])

### 主干四：MMR 选择循环——λ 权衡相关性与多样性（W-F34-3 本体）

伪代码 — app/rag/ranker.py:MMR选样（行族内部步——复合档选样实现，主干叙述件）

def MMR选样(self, 过阈列, top_n, λ=0.7) -> Ranked:
    # 主干判断①冗余度量：每候选分词成词集（清洗后正文——与打分同一输入形状），
    #   冗余=与"已选集"每个词集的 Jaccard 取**最大**（不是平均——最像的那个
    #   已选块才决定惩罚；WeKnora applyMMR :496-501 同构）
    词集列 = [分词集合(c.清洗正文) for c in 过阈列]
    已选序号 = []
    结果列 = []
    # 主干判断②贪心选择循环：每轮从未选里挑 MMR 分最高者，选满 top_n 或选完为止
    while len(结果列) < top_n and len(已选序号) < len(过阈列):
        最佳 = None
        for i, 候选 in enumerate(过阈列):
            if i in 已选序号: continue
            相关性 = 候选.拆账["复合分"]              # 相关性项=复合分（MMR 吃加权后分数）
            冗余 = max((Jaccard(词集列[i], 词集列[j]) for j in 已选序号), default=0.0)
            mmr = λ*相关性 − (1−λ)*冗余               # λ=0.7：七成相关性三成反冗余（:503 同式）
            if 最佳 is None or mmr > 最佳.分: 最佳 = (i, mmr)
        已选序号.append(最佳.序号)
        结果列.append(过阈列[最佳.序号])
    # 主干判断③选择序=最终序：MMR 每轮选出的顺序就是返回顺序（不再是纯分数
    #   降序——多样性折算可能让次高分插队，这正是 W-F34-3 要的行为）
    return Ranked(候选=结果列)
```

闸在哪：①前 N 边界闸（主干一①——入参即融合池前 N，无全量入口不回读召回层，设计范围边界红线）；②空候选短路闸（主干一①——空进空出不造分，下游拒答闸原样接）；③调用计数闸（主干二①+成本账表——LLM 档逐候选调用逐次过 m2 网关记账，计数=N 是 W-F34-2 的可验证判据）；④解析失败回退闸（主干二②——严格单值合同+整档回退融合原序不炸链，破 JSON/越界/部分成功三路同归，W-F34-2 后半句本体）；⑤位次归一闸（主干三①——检索基础分与前 N 位次折算，防 0.3×base 项失声或饱和，WeKnora rescale 注释同动机）；⑥复合分截断闸（主干三③——合成后夹到 [0,1]，WeKnora 同构）；⑦阈值挽回链闸（主干三④⑤——阈值过滤/降阈值一次/top1 保底/全空信号四段各有判据，兜底衔接设计稿 47 零新增函数）；⑧MMR 多样性闸（主干四——λ=0.7 权衡式+最大 Jaccard 冗余+贪心选择，近重复段落让位，W-F34-3 本体）。拦完数据去哪：解析失败档=原序候选+告警入册+已花调用照记账（失败只收延迟费不收错误帧）；低分候选=被阈值族滤出后即弃（不落库不留痕——出局就是出局）；三段近重复=只留复合分最高的一段，其余被冗余惩罚挤出 top-n（不是删除——它们仍在候选集里，只是排不进前列）；全空=信号交给设计稿 47 兜底两态，用户侧收场与检索空无差别。

## 关键判断的取舍记录

1. **三档是选项制同场对照，缺省模型档——"统一最优档"不存在。** 备选"只实现复合档当唯一重排"：否决理由——三档各答一个真实约束（PRD 选项矩阵第 6 行：延迟敏感→模型；精度优先不怕贵→LLM；多样性敏感→MMR），LLM 档 N 次调用的延迟与费用在小李高频提问场景不可接受，模型档的纯分数降序在"各区块产量对比"类问题上又真会被近重复占满（走查推演 2 t1）——没有一根尺子量所有场景；且缺省档若不是模型档，设计稿 10 升级后行为就变了，反断言无处安放。落定：按库配置三选一、缺省模型档、模型档=既有 `rerank` 原样委托（主干一②③；WeKnora 侧同构是"未配重排模型就融合序直通"的跳过位 ：57-62——WeKnora 用跳过、本设计稿用缺省，三档都有底）。换边条件：设计稿 11 RAGAS 评估若证明某档在报告库语料上全面占优，可在配置缺省上换档——分派结构不动。
2. **检索基础分取前 N 位次归一，不直接吃 RRF 原始分。** 备选一"直接用 RRF 分当 base"：否决理由——k=60 的 RRF 分量级 ~0.03，0.3×base 项贡献 ≈0.01，在复合分里失声，"0.3"权重形同虚设；备选二"用原始召回分（向量余弦/BM25）"：否决理由——两路分数尺子不同且不可跨路比（设计稿 10 主干二口径），BM25 无界分还会饱和复合分（WeKnora fusion :41-43/:83-88 注释原话——"every candidate ties at 1.0 and MMR degenerates to diversity-only ordering"）。落定：前 N 内位次归一到 [0,1]（第 1 名 1.0 线性递减）——前 N 内的相对位次本来就是要比的东西，折算后三成分同一刻度、复合分可直接与阈值对话（主干三①；WeKnora 同动机实测折算单路分，本设计稿折位次，刻度选择不同、动机同一）。代价如实记：位次归一丢掉"第一名领先多少"的强度信息（0.910 与 0.880 的差距被压扁成位次差）——换边条件：设计稿 11 评估若显示头部强度影响生成质量，改吃 WeKnora 式"除以最大有限分"折算，改动收在位次归一一处内部步。
3. **MMR 冗余用词面 Jaccard 不用向量相似。** 备选"冗余=候选间向量余弦"：否决理由——每轮选择都要与已选集逐对算相似度，向量版要么预计算 N×N 相似阵（前 N=20 是 190 对，尚可；N 上千不可行）要么在线调嵌入接口（成本与延迟爆炸）；词面 Jaccard 纯本地计算零调用，且近重复段落（同一对比的换措辞复述）词面重叠度天然极高，判重信号足够（WeKnora 同构实测：`TokenizeSimple`+`Jaccard`，:474-477 预计算词集）。落定：词面 Jaccard 取最大已选冗余（主干四①）。代价如实记：语义同文不同的重复（换个词讲同一件事）词面判不到——换边条件：设计稿 11 评估若显示语义级重复漏网成主诉，冗余度量换嵌入余弦并把 N 压到预计算可行的小窗口（改动收在冗余一处内部步）。
4. **阈值是每档各自的标定物，不共用一个数。** 备选"全档共用设计稿 10 的无据拒答阈值"：否决理由——分数语义不同（设计稿 10 闸读的是 normalize=True 的跨编码器分，复合档的首名分是三成分加权后的复合分），同一个 0.5 在两把刻度上含义不同；生成侧拒答闸判据（候选空或全低分）是形状合同，读的分数值本来就该随档位重标定。落定：复合档自带复合阈值（主干三④），模型档保持设计稿 10 原状（反断言），生成侧判据形状零改动——W-F6-5 的"全低分"判分落在生成闸不变，复合档只是给它喂另一把尺子量过的分（与设计稿 10 取舍 2"拒答阈值收在精排之后"同一哲学：没有刻度的尺子不刻度，有刻度的尺子各自标定）。
5. **解析失败整档回退，不做单候选跳过。** 备选一"失败候选保留原序位、其余按 LLM 分排序"：否决理由——19 个新分数+1 个原序位=半新半旧排序，失败候选前后是谁全凭运气，"这条为什么排这"在拆账里无账可查（可解释性是 W-F34-1 立的招牌，排序口径不能自破）；备选二"失败候选内联重试一次"：否决理由——重试是网关既有面的职责（设计稿 07 重试/冷却契约），Ranker 层再叠一层重试=两层重试语义打架，且把失败延迟翻倍。落定：任一候选解析失败（破 JSON/越界/空值同判）→ 整档回退融合原序+告警入册+已花调用照记账（主干二②；WeKnora 同构整档回原序 :137——"pipeline can still return something useful"的语义就是降级交完整结果，不交拼盘）。代价如实记：20 个候选 1 个失败要白花 19 次调用的费用——概率上 LLM 单值打分的解析成功率极高（输出合同极短），整档回退的期望成本低于半旧排序的排障成本；换边条件：若设计稿 11 评估显示解析失败率不可忽略，升级为"失败候选单独重打一次，再失败才整档回退"——改动收在解析单值一处内部步。
6. **学习型排序一句划界：三档覆盖三轴，冷启动不欠第四轴的债。** 设计范围"不做学习型排序"。一句设计：学习型排序（LTR——用点击/标注数据训练排序模型）要训练数据与持续标注，平台报告库冷启动期两样都没有；且三档已覆盖延迟/精度/多样性三轴，LTR 换来的是第四轴（个性化）——报告库场景"哪份报告相关"不随人变（油藏口径是客观的），第四轴暂无业务收益。留好的接口位：`rerank_composite` 的输出形状（Ranked）与档位分派结构天然可挂第四档（配置枚举加一项即可），分派与下游零改动——真要上 LTR 时新增的是档位实现不是管道改造。
