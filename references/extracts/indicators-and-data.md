### 2.1 井口→实时库→生产库→上报的完整链路（陈海娜，最完整）

## 三、指标关系映射

### 3.1 监测指标 → 开发指标（蒋华，核心映射清单）

单井监测解释参数四类（原文逐字）：
1. 吸水剖面解释参数：相对吸水量、单井测试层吸水厚度、单井总吸水厚度、单井吸水量；
2. 产出剖面解释参数：单井测试层产油量、单井总产油量、单井测试层产油厚度、单井测试层产液量、单井总产液量、单井测试层产液厚度；
3. 试井相关输入输出参数：有效渗透率、有效厚度、地层流体粘度、关井时间、地层孔隙度、综合压缩系数；
4. 压力监测数据：生产井流压、生产井静压、注水井静压、注水井流压。

单井参数聚合为 5 个区块监测指标特征："区块吸水能力、区块产油能力、区块产液能力、区块渗流能力和区块压力保持水平"。

系统模拟输入→输出映射（原文变量逐字）：
- 输入：x₁(t)＝区块吸水能力；x₂(t)＝区块产油能力；x₃(t)＝区块产液能力
- 输出：u₁(t)＝区块月产液量；u₂(t)＝区块月产油量；u₃(t)＝区块月注水量；u₄(t)＝累积产液量；u₅(t)＝累积产油量；u₆(t)＝累积产水量
- 另一组可做关联分析的开发指标（原文逐字）："区块产液量（月）、区块注水量（月）、累积产液量、累积产油量、累积注水量、月采出程度、月注采比、综合含水率、总递减率等与区块监测指标特征关联度的大小"。

### 3.2 前置指标 → 结果指标（灰色关联度，党晨表2-1 全量照录）

以含水率为参考序列，17 项比较指标关联度排序：产油量 0.98（1）、油压 0.94（2）、套压 0.93（3）、注水量 0.91（4）、生产时间 0.90（5）、动液面 0.89（6）、日产水量 0.88（7）、采油速率 0.86（8）、静压 0.84（9）、水气比 0.83（10）、采出程度 0.82（11）、日注气量 0.81（12）、含砂率 0.78（13）、气油比 0.77（14）、注入方式 0.75（15）、流压 0.71（16）、日产液量 0.69（17）。结论："对含水率影响程度最大的指标是产油量(0.98)，然后依次是油压(0.94)，套压(0.93)，注水量(0.91)，生产时间(0.90)和动液面(0.89)，故选取这六项作为后续神经网络的输入。"

预警六要素链（党晨）：警源（"导致油田开发指标异常变化的根源"）→ 警情（"油田开发指标的异常状态"）→ 警素（"警源中影响警情变化的因素。在油田开发指标预警中，影响含水率的因素油田产量、油压、套压、注水量、动液面等"）→ 警兆（"一个指标的变化会引起另一个指标的相应变化，前者是后者的预警信号"）→ 警限（"安全与风险之间的微妙界限"）→ 警度（偏离程度分级）。

### 3.3 措施 → 递减 → 含水 → 增油（王飞，措施链映射）

- 水井措施因果链（摘要原文）："注水井措施对减缓递减、控制含水上升保障油田基础产量具有重要意义"。"注水井措施与油井措施不同，作业后不直接实现增油，而是通过注水井措施补充能量减缓递减或潜力层加强驱替动用从而实现增油。"
- 增油拆解关系（式10 语义）：评估年措施增油量 Q_j＝评估年总产量 A−评估年递减产量 B−评估年油井措施产量 C，即"水井措施受效油井当年增油量＝实际产量−自然递减产量−油井措施增油"。
- 措施类型与技术指标对应（原文逐字）：酸化解堵/注水压力优化→"措施后视吸水指数初增倍数大于 0 为措施有效"；调剖调驱→"典型提高注水井有效注入的措施"，"措施后视吸水指数初增倍比小于 0 或霍尔曲线斜率上升为措施无效"；分层调配→"措施后全井各层段均合格满足油藏需求为措施有效"；修井、转注、分注→"措施后需要同时满足管柱强度和防腐达标、管柱验封合格、安全隐患消除等要求为措施有效"。
- 实证量级（表1/表2，可作业务案例引用）：1600 井次措施，有效率超过 95%；油井受效率近 90%；当年平均单井增油超过 1000t；预测有效期内平均单井增油近 2000t；转注/分注有效期最长 3700~4000d、预测单井增油 62000~65000t；分层调配 940 井次为工作量最大措施。
- 依据标准：SY/T 5849—2018《油水井化学剂解堵效果评价方法》、SY/T 6334—2013《油水井酸化设计施工及评价规范》、SY/T 5588—2012《注水井调剖工艺及效果评价》、Q/HS 2049—2009《海上油田化学剂解堵效果评价技术方法》、Q/HS 2075—2017《注水井分注工艺作业实施、质量评价和检验要求》。

### 3.4 机理联动关系（薛陈斌，物质平衡三指标联动）

- 注采平衡（式3-1）：Bo·Np＋Bw·Wp＝N·Boi·Ct·(Pi−P)＋Bw·Wi——"根据物质平衡原理，采出量等于地下的膨胀量"。
- 三指标联动（式3-3→3-6）：q_o·Bo＋q_w·Bw−q_i·Bw＝N·Boi·Ct·d(P)/dt，代入注采比定义(3-4)与含水公式(3-5)，得"含水与压力恢复速度、产油量、注采比之间的关系式"（式3-6）。设计含义：注采比、含水率、地层压力恢复速度、产油量四者由物质平衡方程强约束，任一指标预测须与其余指标自洽。
- 开发阶段划分知识（薛陈斌 2.1.2，奥鲁德涅夫四阶段）：①油藏投产阶段（"产量急剧增加"）→②高产稳产阶段（"油田开发生产的黄金时期"）→③产量递减阶段（"各种矛盾交织、调整控制频繁、采油成本急剧上升"）→④低产阶段；薛陈斌将③④合并为"产量提升、产量稳定与产量递减三个阶段"。
- 递减方程族关系："双曲递减表达式中，当 n 取值为 1 时，即可等价为调和递减表达式；当 n 取值为−1 时，即可等价为直线递减表达式；当 n 取值为 1/2 时，即可等价为衰竭递减表达式。"

### 3.6 成本指标 → 生产指标联动（华志勇）

- 层级传导："单井三线四区评估结果 → 区块四维评估线/五类价值区 → 采油厂五类价值区（高价值区、中等价值区、潜力价值区、低价值区、风险区）"。
- 措施决策映射："根据单井的'三线四区'评估结果，可评估增产措施的经济性，并判断单井是否值得继续投资。对盈利高效井优先配置资源……对边际有效井要开展成本结构分析，实施低成本的增产措施"。
- 分摊关系：集输成本按产量比例分摊、注水成本按注水量比例分摊（成本指标依赖生产指标作分摊因子）。

### 3.7 能效指标 ← 生产/运行参数映射（郭以东图1）

机采系统工艺过程能效管理指标的数据源分布（原文图1 逐字归纳）：
- A2、A5、A11 三系统共同覆盖：生产能力、开井数、总装机容量、主要机采类型；
- A5 覆盖：平均单井日产液、年机采总耗电；
- A5、E7 共同覆盖（能耗评价指标）：抽油机井系统效率、电泵井系统效率、螺杆泵井系统效率、机采系统平均效率、抽油机井吨液百米单耗、电泵井吨液百米单耗、螺杆泵井吨液百米单耗、机采吨液百米单耗；
- 运行指标（多源）：气油比、渗透率、平均冲次、平均冲程、油藏深度、采出液综合含水、井口油管压力、井口平均回压、井口套管压力、采出液密度、原油凝固点、平均单井动液面深度、含蜡量、井口平均出油温度、油气田分类。

### 3.8 能效指标内部权重结构（曹莹）

- 系统级主导："在以较大权重计入系统级指标的同时，以较小的权重计入主要影响因素"；"如果系统级指标是优良，但其单元级或设备级指标有部分合格或不合格，可能会使得系统综合能效评价等级从只评价系统级指标所得到的'优秀'降为综合评价所得到的'良好'或'中等'"。
- 实例（表6 第 6 口井）："虽然系统效率和采液单耗均为优良，但由于电动机功率利用率不合格、泵效仅为合格，导致系统的综合能效评价等级为良好。"

1. "以措施注水井为中心，以受效油井为目标，以递减增油为量化评价数据，从注采两端评估水井措施，首次从水井技术指标、油井增油指标、油水井成本指标 3 个维度，对海上油田注水井措施进行了量化评估。"——王飞（摘要）
2. "油井措施可直接劈分计算增油量，而注水井措施评估工作尚无方法可借鉴，且注水井措施因工作量大、多措施叠加，建立有效的量化增油方法难度大。"——王飞
3. "目前注水井措施增油计算方法在行业内尚处于空白阶段，尚未量化评价注水井措施的实际增油效果。"——王飞
4. "注水井措施与油井措施不同，作业后不直接实现增油，而是通过注水井措施补充能量减缓递减或潜力层加强驱替动用从而实现增油。"——王飞
5. "我国海上油田注水井措施作业量急剧增加，每年注水井措施作业量是油井的 3 倍，而注水井受效油井超 5000 井次，使得油田作业难度及成本不断攀升，亟待开展水井措施系统评估。"——王飞
