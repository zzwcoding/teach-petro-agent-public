Petro-Agent 油田智能平台 A2A AgentCard（设计稿）

本页是平台对外暴露的 Agent 名片——外部 Agent 通过它发现平台技能；静态页即 AgentCard 样例的渲染形态。

身份

namepetro-agent
description渤海油田数据智能平台：报告问答（RAG）/ 生产数据问数（Text2SQL + 语义层）/ 多模态成品生成（问智）/ 语义资产治理（4+1 能力域 + 五级 CI）。
provider虚构设定项目（组织与人名均为虚构设定）——非真实部署服务
protocolVersionA2A 形状设计演绎；传输与端点未实装

skills（技能声明）

qa · 报告问答带页码引用的流式回答；无据拒答双闸。
text2sql · 生产问数自然语言→确定性 SQL；语义层直绑 verified metric；执行前五道关；检索瀑布 @锚定直达。
wenzhi · 问智生成PPT/图/语音成品；受理即回 + 任务句柄（Tasks 映射同构）。
semantic-governance · 口径治理口径变更过五级 CI + Owner 审批；只提 MR 四红线；Ossie 格式导出。

endpoints & authentication（设计演绎）

endpointmcp://petro-agent（形态示意——不搭真实例）
authentication服务账号 + 角色档（外部 Agent 默认只读档）；行权限随档注入
capabilitiestools: 只读查库/导航elicitation: 缺参主动问tasks: 异步成品外发通道: 无

同权同闸：外部 Agent 的工具清单 = 注册表可见性过滤结果；越权拒绝与内部幻觉调用同一形状。大结果一律回 artifact 句柄 + 5 行预览。
