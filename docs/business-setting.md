## 2. 数据源与采集链路

### 2.1 真实采集链路（行业锚，本设定按此缩放）[陈海娜]
五层：**井口传感器（1 万 RTU、秒级采样）→ Modbus TCP 上传 → 边缘计算 → 实时库（InfluxDB 类）→ ETL 入数据仓库（15 分钟级闭环调度）**。行业系统清单（郭以东）：A1/A2（生产上报）、A5（站库计量）、A6（协同研究）、A11（勘探开发数据管理）、E7（统计上报）等——**"一数四源"**（§3.1）的物理来源。本设定：五层压成"井口→实时库→生产库（8 表）→平台"，手工录入环节保留（班次报表）——它是脏数据的主要来源。

### 2.2 生产域 8 表字典（DDL 级）

> 完整字段/类型/单位/脏特征/样本行沿用 business-setting v2 §2（本版不重复，**该节升级为本设定书的附录 A**：well_info / oil_production_daily / water_injection_daily / well_overhaul / well_measures / fluid_test / equip_status / monthly_settlement，含 A/B 班重复行、吨方混写、T-3 补录、新旧编码并存等样本）。新增两处以对齐提取件：

**指标不是独立数字**（物质平衡约束 [薛陈斌]）：注采比 β、含水率 f_w、压力恢复速度、产油量 q_o 由物质平衡方程强约束——修改任一口径必须检查联动指标（L4 影响分析的素材）。
**"一数四源"真实案例** [郭以东]：同一"油气产量"在 A11（实时加和）、A2（上报审核）、A5（站库计量）、E7（统计上报）四个系统数值互不一致，差异原因=统计口径、计量误差、损耗、测算方式、精度累计、统计周期——**事故 13**（v3 口径争议的最佳真实案例，替代部分虚构叙事）。

## 5. Ontology 域草案

- **实体**：井（well_id/井别/投产日/状态机）、井筒（段/射孔/防砂）、区块、油田、平台、设备、措施、化验样、**受效关系**（注水井→受效油井，多对多，属性=劈分系数 Σ=1、响应起始日——由王飞系数劈分 [6] 强制要求，业务规则驱动建模的实证）、配注层。
- **关系**：井—隶属→区块—隶属→油田；平台—承载→井；注水井—受效→油井；措施—作用于→井；化验样—取样自→井。
- **合法 Join 白名单**（默认拒绝）：oil_production_daily ⋈ well_info（井号）✓；oil_production_daily ⋈ date_dim ✓；oil_production_daily ⋈ fluid_test **✗**（须井号+取样日期双键+时间容差，经 intermediate 视图）；oil_production_daily ⋈ water_injection_daily 直连 **✗**（须经受效关系实体）。

### A.2 `oil_production_daily` 日产计量（一井一日；PK well_id+prod_date）★核心事实源
well_id / prod_date / oil_output DECIMAL(10,2) 吨（个别行误录为方）/ liquid_output 方 / water_cut %(化验折算，与 fluid_test 打架) / plan_output 吨（配产版本切换日双值行）/ open_days 天（停井日仍>0 矛盾行）/ oil_pressure MPa / report_shift CHAR(1) A/B/C（**班次手抄汇总**：同井同日 A/B 两行）。
样本：`N-02|2026-09-14|48.60|165.30|70.6|50.00|24|3.1|A`；`N-02|2026-09-14|48.60|165.30|70.6|50.00|24|3.1|B ←重复行`；`N-11|2026-09-14|12.40方|96.00|87.1|15.00|6.5|2.7|A ←油单位误录`。

### A.3 `water_injection_daily`（井号+日期）：inj_volume 方 / pump_pressure MPa / layer_split（`P1:60,P2:40`；两层/三层口径不一、偶为累计值）。
### A.4 `well_overhaul`（井号+起止）：overhaul_start/end DATE（**跨月** 8-28→9-06：当月口径切割争议源）/ overhaul_type / affected_output 吨（各作业区估算口径不一）/ batch_id（**补录**：N-11 batch=20260911-T3——T-3 补录案例源）。样本：`N-11|2026-08-28→2026-09-06|检泵|约210吨|20260911-T3`。
### A.5 `well_measures`（井号+措施次）：measure_type(压裂/酸化/补孔/调剖)/job_date/effective_from·to（**30% 缺失**——数据体检规则素材）/incr_oil_annual 吨（递减增油口径，两作业区算法不一致=事故 7）。
### A.6 `fluid_test`（井号+取样日期）：water_cut_lab/density/api_gravity；频次不齐（高产周报/低产半月报），缺失插补规则争议。
### A.7 `equip_status`（设备号+时间戳）：equip_type(电泵/螺杆泵/加热炉)/load/current/stop_reason_code（**新旧编码并存**：旧 R3=皮带断，新 BELT——归一化素材）。
### A.8 `monthly_settlement`（区块+结算月）：block_name/settle_date/net_weight 吨（扣自用油与输差；与井口口径天然不等——事故 7 另一面）。
