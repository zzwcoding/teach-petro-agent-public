# Petro-Agent 真实开发路线图（v1 · 2026-09-29 Owner 拍板）

> 依据：21 册 API 合同（specs/api/）+ 98 模块划分 + 99 数据库与连接层 + ADR-0003（技术选型）+ ADR-0004（本体真源与 all-agent 衔接）。
> 格局：**主平台单体（Python 3.12 + uv · FastAPI · asyncio 链体〔LangGraph 未引入，2026-10-02 登记〕· LiteLLM 内嵌）+ 数据面独立服务（数据面服务仓 v2）+ 本体仓（all-agent 式，ontology/）**；中间件五件 PG/Redis/MinIO/Neo4j/Langfuse。

## 总格局：一条主轨道 + 两条并行轨道

```
轨道 0 · 本体建造冲刺（all-agent 验证主场，可与阶段 0 并行，阶段 1 开工前就绪）
主轨道 · 主平台五阶段（0 地基 → 1 知识问答 → 2 问数井档 → 3 治理链 → 4 对外）
并行轨道 · 数据面 v2（阶段 1 期间开工，阶段 2 开工前就绪）
```

## 每阶段的开工闸（Owner 流程）

**开阶段前检查该阶段页面清单：涉及未整理页面 → Owner 先整理 → 主控改对应合同册/PRD 对齐 → 设计复核 → 才开工。**
