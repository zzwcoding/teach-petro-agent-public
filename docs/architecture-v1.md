## 三、核心链路（用户视角四条线）

**① 问答链（阶段 1 上线）**
```
用户提问 → chat 四层流水线：安检(security) → 六路装配(术语/指标/FAQ/报告/工具/工作流)
  → 意图裁决(LiteLLM) → 17 链分派
    ├─ 检索问答链 → kb 索引 → 答案+出处(cN 引用→B2 切片回跳)
    ├─ FAQ 秒回链 → faq 索引 → 直接答(不走模型)
    └─ 图谱问答链 → Neo4j 遍历+台账映射卡 → 关系答案
  → SSE 事件帧流回前端（思考过程树路径叙事）
  └─ 分析结果留会话内，供④问智链消费（产物不进出对话上下文，以句柄出门）
```

**② 问数链（阶段 2 上线）**
```
用户提问 → 裁决=问数 → 状态机六站：选表(评分卡) → 生成SQL → 安检三闸
  (只读白名单/强制限量/行级权限——security) → 执行(agg 汇总表) → 反思修正(≤3次)
  → 结果+解释链五要素（这个数怎么来的）
  └─ 大结果：落 MinIO 给取货凭证（预签名直链 7 天）
```

**③ 治理链（阶段 3 上线，all-agent 验证主场）**
```
答错/体检/反馈 → C2 提案池（来源×目标准入矩阵）→ 负责人批准
  → 自动提交 MR → 本体仓 语义 CI(L1-L5+L3-5 口径机检闸) → 合入
  → 同步器 sync_from_ontology_repo（钉版1.1.0）→ 台账行版本+1
  → semantic.current 推进 → 全平台按新口径作答（可回滚）
考核线：E1 跑批 → 当前基准单例 → C3 第五道检查（行为回归）
```

**④ 问智链（成品链：问答+问数结合 · 框架阶段 1 上线）**
```
主任要成品："把这份分析做成汇报 PPT，配张示意图"
  → 前提：同一会话内分析结果已汇合——①问答链的检索答案/引用
    ＋②问数链的图表/取货凭证（问数上线前仅消费①的产物）
  → POST /api/chat/artifacts 受理（kind=ppt|img|audio，挂 message_id）
    → 202 任务号，不阻塞对话
  → Redis Streams 队列 → 问智 worker（chat 模块异步消费进程）：
    LLM 把会话产物汇总成 briefing → 生成器
    ├─ PPT：python-pptx 模板驱动（进阶=提议者-审核者：渲染截图交视觉模型审排版）
    ├─ 配图：万相异步文生图（转存义务：URL 24h 过期 → 下载落 MinIO）
    └─ 语音：edge-tts 解读（ASR 语音提问=FunASR，走网关 OpenAI 兼容口）
  → MinIO artifacts 桶 + 元数据入库（F3 表）→ GET 轮询回产物卡
    （预签名下载直链；四步固定：素材→草稿→成品→下载直链）
阶段落位：受理/队列/产物卡框架＝阶段 1 建成；各生成器按内网多模态
模型可用性逐个点亮（roadmap 既定）；LLM 由 Owner 提供多模态能力
```

## 四、数据流与对接面

- **数据面**：中台 8 张源表 → 进料三步（校验→入库→登记水位）→ 三层加工 → agg 三表（fct_daily_metering/dim_well/dim_date）直写主平台 PG（限写三表专用账号）；主平台 /api/ingest/* 经 HTTP API 拉投影，零共享库；新鲜度唯一真源=dp2 FreshnessRegistry
- **本体仓**：Git+YAML 唯一真源（术语 11＝复用 10+新增 1／指标 15／对象 10＋m1 含 4 个四维空壳雏形位／关系 5／白名单 4／工作流 10／Action 3）→ 语义闸（L1–L5+L3-5 口径机检）→ 同步器投影为台账 DB 行（禁手改）
- **观测**：每次 LLM 调用 → gateway 记账（模型/token/耗时/金额）→ Langfuse 链路；D5 页面已撤（2026-10-01 撤页归并 D1）——花费聚合与预算熔断阈值归 D1 页面（合同 D1 v0.2）、链路回看走 Langfuse 外链
- **安全**：全部数据面过 D3 安检（只读闸/表白名单/限量/行级权限）；国密 SM4 字段加密；审计唯一写口 security.audit
