# ADR-0002：统一入口决策链（D1 字面安检 → D2 装配意图判定 → 可复用执行链）

- 日期：2026-09-26
- 状态：已拍板（用户于原型多轮重构后定稿页面形态，指示按此回写项目）
- 关联：ADR-0001（V2 技术栈）· 变更请求 docs/change-requests/2026-09-26-a1-routing-redesign.md · 总开发票

## 背景

项目文档的入口设计是"按端点分链"（PRD F1：`POST /chat/{agent}`，agent 由客户端指定，m13 dispatch 按 agent_type 三分支）。原型 A1 页在设计中演进为统一入口 + 多链路形态，与文档出现系统性出入。

## 决策

统一入口按四层流水线组织，**所有问句无例外**经过 LLM + 系统提示词识别：

1. **D1 统一安检（确定性字面规则，零理解成本）**：注入特征扫描 · 禁用词索引（0 号位，先于一切解析）· 身份认证与数据域解析。任一 ✗ 即拦截出终局。
   - 关键裁决：**外发判定不在 D1**——"想外发"是意图，判定它需要听懂问句；D1 只放不需要理解的字面检查。
2. **知识装配**：实体锚定（问句→本体 ID）→ 一跳闭包扩展 → 候选清单＋置信度；用户 @ 显式倾向在此注入提示词（**倾向≠直通**：模型仍需核验槽位合格性，不齐走澄清帧）。
3. **D2 意图判定（LLM·装配提示词·闭世界）**：系统提示词=通用规则＋本轮装配知识＋执行链闭世界枚举；模型结构化输出 `{chain, slots(本体ID), confidence, need_clarify}`；低置信/缺参→澄清帧（interrupt 挂起，回 D2 重判）。
4. **分支执行**：22 条路径 / 17 条可复用执行链（含复用），链内闸门由代码值守（模型选路线，无权改交规）。

## 推翻的旧假设

| 旧假设 | 出处 | 新裁决 |
|---|---|---|
| 入口按端点分链，agent 由客户端传入 | PRD F1，m13 | 统一入口；agent_type 由 D2 裁决产出 |
| 匹配器（FAQ/指标卡/术语）可作路由裁决 | 原型早期实现 | 匹配器降级为"装配候选"，裁决权唯一归 D2 模型 |
| 外发拦截属字面安检 | 原型早期实现 | 外发=意图出口（D2 分支） |
| 显式 @/点名可直接调用 | 原型中期实现 | @=倾向注入，模型核验槽位后执行 |

## 后果

- 新增 W 断言族（D1/D2/倾向/外发）；新增设计稿补全局路由层伪代码。
- 链内合同（W-F14/W-F19/W-F21/W-F7-1）与 FAQ 同池闸（设计稿 49）**保持不变**。

## 不做的事

- 不改 m6/m7 隔离边界（装配层只读公开面，走既有 Seam 先例）。
