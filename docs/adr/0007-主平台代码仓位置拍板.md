# ADR-0007：主平台代码仓位置拍板（平台实现仓 建仓）

- 日期：2026-09-29
- 状态：已接受（Owner 拍板：选项 A——新建独立仓，后端+前端同仓）
- 关联：ADR-0005 §3（本决策的预留出处）· ADR-0006（前端底座裁决的落位修订）

## 裁决

真实主平台代码建仓 **`平台实现仓`**（git 独立仓），布局：

```
平台实现仓/
├── app/            # 后端：Python 3.12 + uv · FastAPI（98 册四层：api/domains/infra）
├── web/            # 前端：prototype/app fork 改造（ADR-0006 底座五件落此处）
├── compose.yaml    # 中间件五件编排（PG+pgvector/Redis/MinIO/Neo4j/Langfuse）
└── .github/workflows/  # CI 四门禁
```

- **数据面不动**：维持已有 `数据面服务仓` 独立仓（v2 重排后续在其仓内做大版本）。
- **设计文档不动**：21 册合同/架构图/roadmap 真源留在 `本仓（设计真源）`（设计仓），代码仓只放实现；两仓靠合同锚点引用，不复制合同正文。
- **ADR-0006 措辞修订**：前端底座"在 prototype/app/ 工程上补底座"落实为"**prototype fork 为 web/ 后补底座**"——`本仓（设计真源）/prototype/` 保持设计资产不动（继续承担未整理页面的产品化迭代），`web/` 是其冻结快照的代码化 fork。底座五件语义不变。

## 理由

- 与 本体仓 / 数据面服务仓 同模式：**三仓鼎立**（主平台/本体/数据面），一仓一责；
- 后端+前端同仓：阶段 0 的 D1 落地与接口对齐可一次提交，compose/CI 一体；
- 设计仓保持纯设计/文档仓：设计轨冻结纪律与 CI 噪音互不干扰。
